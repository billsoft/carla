## 二、当前版本对比分析

| 参数 | Standard | Lite | Mini | Nano |
|------|----------|------|------|------|
| **patch_size** | 8 | 16 | 16 | CNN backbone |
| **embed_dim** | 256 | 256 | 192 | 128 |

| **显存(BS=1)** | ~8-12GB | ~4-6GB | ~3-4GB | ~1GB |

### Standard 版 OOM 原因分析

```
序列长度对比：

Standard: 8 × (480/8) × (640/8) = 8 × 60 × 80 = 38,400 tokens
Mini:     8 × (480/16) × (640/16) = 8 × 30 × 40 = 9,600 tokens

Attention 矩阵大小对比：

Standard Encoder: 38,400 × 38,400 = 1.47B 元素 (使用窗口注意力后约 38,400 × 64 = 2.5M)
Standard Decoder Cross-Attn: 20,000 × 38,400 = 768M 元素 ← 主要显存消耗！

Mini Decoder Cross-Attn: 2,500 × 9,600 = 24M 元素
```

**关键发现**：Standard 版的 Cross-Attention 是显存爆炸的主因！

## 三、Balanced 版本设计

### 3.1 设计原则

1. **从 Standard 简化**：减少序列长度，降低 Cross-Attention 开销
2. **从 Mini 增强**：增加 embed_dim 和 decoder 深度，提升表达能力
3. **平衡点**：显存控制在 4-6GB，精度预期 mIoU 35-40%

### 3.2 配置参数

```python
class TransformerOccNetBalanced(nn.Module):
    """
    Balanced 版本配置：
    - 显存: ~4-6GB (BS=1, AMP)
    - 参数量: ~18M
    - 预期 mIoU: 35-40%
    """
    
    def __init__(
        self,
        # === 输入配置 ===
        num_cameras: int = 8,
        img_size: Tuple[int, int] = (960, 1280),
        
        # === Patch Embedding ===
        patch_size: int = 16,           # 与 Mini 相同，控制序列长度
        embed_dim: int = 256,           # 与 Standard 相同，保持表达能力
        
        # === Encoder ===
        encoder_layers: int = 4,        # 比 Standard 少 2 层
        num_heads: int = 8,             # 保持 8 头
        ffn_dim: int = 1024,            # 4 × embed_dim
        window_size: int = 8,           # 窗口注意力
        
        # === BEV Queries ===
        bev_size: Tuple[int, int] = (75, 75),  # Mini 的 50 和 Lite 的 100 之间
        num_height_levels: int = 8,     # 比 Mini 的 16 少，减少 3D 计算
        
        # === Decoder ===
        decoder_layers: int = 3,        # 比 Mini 少 1 层，但比 Lite 多 1 层
        use_deformable: bool = True,    # 使用可变形注意力
        num_deform_points: int = 4,     # 每 query 4 个参考点
        
        # === Output ===
        output_grid_size: Tuple[int, int, int] = (200, 200, 16),
        num_classes: int = 18,
        
        # === 优化选项 ===
        dropout: float = 0.1,           # 增加 dropout 防止过拟合
        use_checkpoint: bool = True,    # 梯度检查点
    ):
```

### 3.3 数据流与 Shape 变化

```
输入: [B, 8, 1, 960, 1280]
  │
  ▼ PixelUnshuffle(2)
[B, 8, 4, 480, 640]
  │
  ▼ Patch Conv 16×16, s=16
[B, 8, 256, 30, 40]
  │
  ▼ Flatten + Concat
[B, 9600, 256]                    ← 9,600 tokens (与 Mini 相同)
  │
  ▼ + Position Encoding (Spatial + Camera)
[B, 9600, 256]
  │
  ▼ Transformer Encoder × 4 (窗口注意力)
[B, 9600, 256]
  │
  │  BEV Queries: [B, 5625, 256]   ← 75×75 = 5,625 queries
  │       │
  ▼───────┘
  ▼ Cross-Attention (可变形, 4 参考点)
[B, 5625, 256]
  │
  ▼ + Height Expansion (×8 高度层)
[B, 256, 75, 75, 8]
  │
  ▼ 3D Conv Refinement
[B, 256, 75, 75, 8]
  │
  ▼ Progressive Upsample (PixelShuffle)
[B, 18, 200, 200, 16]             ← 最终输出
```

### 3.4 关键设计决策

#### A. 序列长度控制

| 版本 | patch_size | tokens/cam | total | Cross-Attn 规模 |
|------|------------|------------|-------|-----------------|
| Standard | 8 | 4,800 | 38,400 | 768M |
| **Balanced** | **16** | **1,200** | **9,600** | **54M** |
| Mini | 16 | 1,200 | 9,600 | 24M |

Balanced 的 Cross-Attention 规模：5,625 × 9,600 = 54M（可控）

#### B. BEV 分辨率选择

```
BEV 75×75 在 50m 范围内：
- 分辨率: 50m / 75 = 0.67m/cell
- 比 Mini 的 1m/cell 更精细
- 比 Lite 的 0.5m/cell 略粗但显存友好

体素总数: 75 × 75 × 8 = 45,000
vs Standard: 50 × 50 × 8 = 20,000
vs Mini: 50 × 50 × 16 = 40,000
```

#### C. Decoder 设计

```python
# 使用可变形注意力 + 残差连接
class BalancedDecoder(nn.Module):
    def __init__(self, embed_dim=256, num_layers=3):
        self.layers = nn.ModuleList([
            DecoderLayer(
                embed_dim=embed_dim,
                num_heads=8,
                use_deformable_attn=True,  # 关键！
                num_deform_points=4,
            )
            for _ in range(num_layers)
        ])
```

可变形注意力的优势：
- 每个 query 只关注 4 个学习到的参考点
- 复杂度从 O(Q×K) 降到 O(Q×4)
- 5,625 × 4 = 22,500 vs 5,625 × 9,600 = 54M

## 五、完整代码实现

### 5.1 核心网络结构

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from typing import Tuple, Optional, Dict
import torch.utils.checkpoint as checkpoint


class TransformerOccNetBalanced(nn.Module):
    """
    Transformer Occupancy Network - Balanced 版本
    
    特点：
    1. 序列长度可控 (9,600 tokens)
    2. 可变形 Cross-Attention 节省显存
    3. BEV 75×75 精度合理
    4. 3 层 Decoder 平衡深度与效率
    """
    
    def __init__(
        self,
        num_cameras: int = 8,
        img_size: Tuple[int, int] = (960, 1280),
        patch_size: int = 16,
        embed_dim: int = 256,
        encoder_layers: int = 4,
        decoder_layers: int = 3,
        num_heads: int = 8,
        ffn_dim: int = 1024,
        bev_size: Tuple[int, int] = (75, 75),
        num_height_levels: int = 8,
        output_grid_size: Tuple[int, int, int] = (200, 200, 16),
        num_classes: int = 18,
        dropout: float = 0.1,
        use_checkpoint: bool = True,
    ):
        super().__init__()
        
        self.num_cameras = num_cameras
        self.embed_dim = embed_dim
        self.bev_size = bev_size
        self.num_height_levels = num_height_levels
        self.use_checkpoint = use_checkpoint
        
        # 1. Patch Embedding
        self.patch_embed = MultiCameraPatchEmbed(
            num_cameras=num_cameras,
            img_size=img_size,
            patch_size=patch_size,
            embed_dim=embed_dim
        )
        self.grid_h = self.patch_embed.grid_size[0]  # 30
        self.grid_w = self.patch_embed.grid_size[1]  # 40
        
        # 2. Position Encoding
        self.spatial_pe = Spatial2DPositionEncoding(
            grid_size=self.patch_embed.grid_size,
            embed_dim=embed_dim
        )
        self.camera_pe = CameraPositionEncoding(
            embed_dim=embed_dim,
            num_cameras=num_cameras,
            grid_size=self.patch_embed.grid_size
        )
        
        # 3. Transformer Encoder (窗口注意力)
        self.encoder = TransformerEncoder(
            embed_dim=embed_dim,
            num_layers=encoder_layers,
            num_heads=num_heads,
            ffn_dim=ffn_dim,
            dropout=dropout,
            use_window_attn=True,
            window_size=8,
            use_checkpoint=use_checkpoint
        )
        
        # 4. BEV Queries
        self.bev_queries = BEVQueries(
            bev_size=bev_size,
            num_height_levels=num_height_levels,
            embed_dim=embed_dim
        )
        
        # 5. Decoder (可变形注意力)
        self.decoder = BalancedDecoder(
            embed_dim=embed_dim,
            num_layers=decoder_layers,
            num_heads=num_heads,
            bev_size=bev_size,
            num_height_levels=num_height_levels,
            output_grid_size=output_grid_size,
            num_classes=num_classes,
            use_deformable=True,
            dropout=dropout
        )
        
        self._init_weights()
    
    def _init_weights(self):
        for m in self.modules():
            if isinstance(m, nn.Linear):
                nn.init.trunc_normal_(m.weight, std=0.02)
                if m.bias is not None:
                    nn.init.zeros_(m.bias)
            elif isinstance(m, nn.LayerNorm):
                nn.init.ones_(m.weight)
                nn.init.zeros_(m.bias)
    
    def forward(
        self,
        images: torch.Tensor,
        camera_intrinsics: Optional[torch.Tensor] = None,
        camera_extrinsics: Optional[torch.Tensor] = None,
    ) -> torch.Tensor:
        """
        Args:
            images: [B, 8, 1, H, W] 多相机 Bayer 图像
        Returns:
            occ_logits: [B, num_classes, X, Y, Z]
        """
        B, N_cam = images.shape[:2]
        device = images.device
        
        # 1. Patch Embedding
        patches, _ = self.patch_embed(images)  # [B, 9600, 256]
        
        # 2. Add Position Encoding
        spatial_pe = self.spatial_pe()
        all_pe = []
        for cam_idx in range(N_cam):
            cam_pe = self.camera_pe(cam_idx, B, device=device)
            combined_pe = spatial_pe.unsqueeze(0).expand(B, -1, -1) + cam_pe
            all_pe.append(combined_pe)
        position_embed = torch.cat(all_pe, dim=1)  # [B, 9600, 256]
        
        patches = patches + position_embed
        
        # 3. Encoder
        total_W = self.grid_w * N_cam  # 40 * 8 = 320
        encoded = self.encoder(patches, H=self.grid_h, W=total_W)
        
        # 4. Get BEV Queries
        queries, query_pos, ref_points = self.bev_queries(B)
        
        # 5. Decoder
        spatial_shapes = torch.tensor([[self.grid_h, total_W]], device=device)
        occ_logits = self.decoder(
            query=queries,
            memory=encoded,
            query_pos=query_pos,
            reference_points=ref_points,
            memory_spatial_shapes=spatial_shapes
        )
        
        return occ_logits
    
    def get_params_summary(self) -> Dict[str, float]:
        def count_params(module):
            return sum(p.numel() for p in module.parameters()) / 1e6
        
        return {
            'patch_embed': count_params(self.patch_embed),
            'position_encoding': count_params(self.spatial_pe) + count_params(self.camera_pe),
            'encoder': count_params(self.encoder),
            'bev_queries': count_params(self.bev_queries),
            'decoder': count_params(self.decoder),
            'total': count_params(self)
        }
```

### 5.2 Balanced Decoder 实现

```python
class BalancedDecoder(nn.Module):
    """
    Balanced 版本解码器
    - 可变形 Cross-Attention
    - 渐进式 3D 上采样
    """
    
    def __init__(
        self,
        embed_dim: int = 256,
        num_layers: int = 3,
        num_heads: int = 8,
        bev_size: Tuple[int, int] = (75, 75),
        num_height_levels: int = 8,
        output_grid_size: Tuple[int, int, int] = (200, 200, 16),
        num_classes: int = 18,
        use_deformable: bool = True,
        dropout: float = 0.1,
    ):
        super().__init__()
        
        self.bev_size = bev_size
        self.num_height_levels = num_height_levels
        self.output_grid_size = output_grid_size
        
        # Decoder Layers
        self.layers = nn.ModuleList([
            DecoderLayer(
                embed_dim=embed_dim,
                num_heads=num_heads,
                ffn_dim=embed_dim * 4,
                dropout=dropout,
                use_deformable_attn=use_deformable,
                num_deform_points=4
            )
            for _ in range(num_layers)
        ])
        
        self.norm = nn.LayerNorm(embed_dim)
        
        # Height Expansion: [B, 5625, 256] -> [B, 256, 75, 75, 8]
        self.height_expand = nn.Linear(embed_dim, embed_dim * num_height_levels)
        
        # 3D Refinement
        self.conv3d = nn.Sequential(
            nn.Conv3d(embed_dim, embed_dim, kernel_size=3, padding=1),
            nn.BatchNorm3d(embed_dim),
            nn.ReLU(inplace=True),
            nn.Conv3d(embed_dim, embed_dim, kernel_size=3, padding=1),
            nn.BatchNorm3d(embed_dim),
            nn.ReLU(inplace=True),
        )
        
        # Upsample Head: 75×75×8 -> 200×200×16
        self.upsample_head = self._build_upsample_head(
            embed_dim, num_classes,
            (bev_size[0], bev_size[1], num_height_levels),
            output_grid_size
        )
    
    def _build_upsample_head(self, embed_dim, num_classes, start_size, target_size):
        """构建渐进式上采样头"""
        layers = []
        curr_dim = embed_dim
        curr_size = list(start_size)
        
        # 75 -> 150 -> 200 (XY)
        # 8 -> 16 (Z)
        upsample_configs = [
            (2, 2, 2),   # 75×75×8 -> 150×150×16
            (1.33, 1.33, 1),  # 150×150×16 -> 200×200×16 (实际用插值)
        ]
        
        # 第一次上采样 2×
        layers.extend([
            nn.ConvTranspose3d(curr_dim, curr_dim // 2, 
                               kernel_size=(2, 2, 2), stride=(2, 2, 2)),
            nn.BatchNorm3d(curr_dim // 2),
            nn.ReLU(inplace=True)
        ])
        curr_dim = curr_dim // 2  # 128
        
        # 第二次调整到目标尺寸
        layers.extend([
            nn.Conv3d(curr_dim, curr_dim, kernel_size=3, padding=1),
            nn.BatchNorm3d(curr_dim),
            nn.ReLU(inplace=True)
        ])
        
        # 分类头
        layers.append(nn.Conv3d(curr_dim, num_classes, kernel_size=1))
        
        return nn.Sequential(*layers)
    
    def forward(
        self,
        query: torch.Tensor,
        memory: torch.Tensor,
        query_pos: Optional[torch.Tensor] = None,
        reference_points: Optional[torch.Tensor] = None,
        memory_spatial_shapes: Optional[torch.Tensor] = None,
    ) -> torch.Tensor:
        
        B = query.shape[0]
        H, W = self.bev_size
        
        # Decoder layers
        for layer in self.layers:
            query = layer(
                query=query,
                memory=memory,
                query_pos=query_pos,
                reference_points=reference_points,
                memory_spatial_shapes=memory_spatial_shapes
            )
        
        query = self.norm(query)  # [B, 5625, 256]
        
        # Height expansion
        x = self.height_expand(query)  # [B, 5625, 256*8]
        x = x.view(B, H, W, self.embed_dim, self.num_height_levels)
        x = x.permute(0, 3, 1, 2, 4)  # [B, 256, 75, 75, 8]
        
        # 3D refinement with residual
        x = self.conv3d(x) + x
        
        # Upsample to target size
        x = self.upsample_head(x)  # [B, num_classes, 150, 150, 16]
        
        # 最终插值到 200×200
        x = F.interpolate(x, size=self.output_grid_size, mode='trilinear', align_corners=False)
        
        return x  # [B, 18, 200, 200, 16]
```

### 5.3 BEVQueries 完整实现（修复缺失代码）

```python
class BEVQueries(nn.Module):
    """
    BEV (Bird's Eye View) 查询
    只在 XY 平面查询，然后扩展到 Z 维度
    """
    
    def __init__(
        self,
        bev_size: Tuple[int, int] = (75, 75),
        num_height_levels: int = 8,
        embed_dim: int = 256,
        x_range: Tuple[float, float] = (-25.0, 25.0),
        y_range: Tuple[float, float] = (-25.0, 25.0),
    ):
        super().__init__()
        
        self.bev_size = bev_size
        self.num_height_levels = num_height_levels
        self.embed_dim = embed_dim
        
        H, W = bev_size
        num_queries = H * W
        
        # 可学习的 BEV 查询向量
        self.query_embed = nn.Parameter(torch.zeros(num_queries, embed_dim))
        nn.init.trunc_normal_(self.query_embed, std=0.02)
        
        # 可学习的位置编码
        self.query_pos = nn.Parameter(torch.zeros(num_queries, embed_dim))
        nn.init.trunc_normal_(self.query_pos, std=0.02)
        
        # 生成参考点 (用于可变形注意力)
        y = torch.linspace(0, 1, H)
        x = torch.linspace(0, 1, W)
        yy, xx = torch.meshgrid(y, x, indexing='ij')
        ref_points = torch.stack([xx.flatten(), yy.flatten()], dim=-1)  # [H*W, 2]
        self.register_buffer('ref_points', ref_points)
    
    def forward(self, batch_size: int) -> Tuple[torch.Tensor, torch.Tensor, torch.Tensor]:
        """
        Returns:
            queries: [B, H*W, D] 查询向量
            query_pos: [B, H*W, D] 位置编码
            ref_points: [B, H*W, 2] 参考点坐标
        """
        queries = self.query_embed.unsqueeze(0).expand(batch_size, -1, -1)
        query_pos = self.query_pos.unsqueeze(0).expand(batch_size, -1, -1)
        ref_points = self.ref_points.unsqueeze(0).expand(batch_size, -1, -1)
        
        return queries, query_pos, ref_points
    
    def expand_to_3d(self, bev_features: torch.Tensor) -> torch.Tensor:
        """
        将 BEV 特征扩展到 3D
        
        Args:
            bev_features: [B, H*W, D]
        Returns:
            features_3d: [B, D, H, W, Z]
        """
        B, N, D = bev_features.shape
        H, W = self.bev_size
        Z = self.num_height_levels
        
        # Reshape to BEV grid
        bev = bev_features.view(B, H, W, D).permute(0, 3, 1, 2)  # [B, D, H, W]
        
        # 扩展到 Z 维度
        features_3d = bev.unsqueeze(-1).expand(-1, -1, -1, -1, Z)  # [B, D, H, W, Z]
        
        return features_3d
```
