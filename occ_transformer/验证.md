### ⚠️ 需要关注的问题

#### 1. BEV 分辨率选择

```python
# verify_nano_net.py 用的是 25×25
model = TransformerOccNetNano(
    bev_size=(25, 25),  # ⚠️ 太粗
    ...
)

# 但默认值是 50×50
bev_size: Tuple[int, int] = (50, 50),  # ✅ 更合理
```

**建议**：用 50×50 BEV，否则定位精度受限（50m 范围下 25×25 = 每格 2m）

---

#### 2. Cross-Attention 实现检查

你的 `NanoDecoder` 用的是标准 `nn.MultiheadAttention`：

```python
self.cross_attn = nn.MultiheadAttention(
    embed_dim=embed_dim,
    num_heads=num_heads,
    dropout=dropout,
    batch_first=True
)
```

**复杂度**：625 queries × 2400 keys = **1.5M** (25×25 BEV)
或 2500 queries × 2400 keys = **6M** (50×50 BEV)

这个规模是可接受的，但如果显存紧张可以换成可变形注意力。

---

#### 3. Height 扩展方式

```python
# BEVQueries.expand_to_3d()
self.height_mlp = nn.Sequential(
    nn.Linear(embed_dim, embed_dim),
    nn.LayerNorm(embed_dim),
    nn.GELU(),
    nn.Linear(embed_dim, embed_dim * num_height_levels),
)
```

这里把 BEV 特征通过 MLP 扩展到高度维度，**设计合理**。
