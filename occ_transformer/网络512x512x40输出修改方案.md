# Transformer Occupancy Network 512×512×40 输出修改方案

## 1. 背景与目标

### 当前状态
- **数据集**: 已对齐 nuScenes 标准,体素网格 **512×512×40**, 分辨率 **0.2m**
- **网络输出**: 所有版本均为 **200×200×16** (分辨率 0.5m)
- **问题**: 网络输出分辨率与数据集不匹配,损失精度

### 目标
1. **输出对齐**: 将所有网络版本输出改为 **512×512×40**
2. **显存控制**: 不能显著增加 VRAM 占用 (否则会爆显存)
3. **优雅实现**: 整体架构考虑,不仅仅改输出层
4. **能力保持**: 保证网络的表达能力不降低

### 涉及范围
- **网络结构**: 4 个版本 (Nano, Mini, Balanced, Standard)
- **训练脚本**: train_nano.py, train_mini.py, train_balanced.py, train_standard.py
- **推理脚本**: inference_transformer.py
- **核心模块**: decoder.py, voxel_query.py

---

## 2. 当前架构分析

### 2.1 网络版本对比

| 版本 | BEV Size | Num Height | Query Count | Encoder Layers | Decoder Layers | 目标 VRAM |
|------|----------|------------|-------------|----------------|----------------|-----------|
| Nano | 50×50 | 8 | 2,500 | 3 | 1 | <4GB |
| Mini | 75×75 | 8 | 5,625 | 6 | 3 | ~6GB |
| Balanced | 100×100 | 16 | 10,000 | 10 | 6 | ~8GB |
| Standard | 100×100 | 16 | 10,000 | 12 | 6 | >10GB |

### 2.2 解码器上采样策略

**原有流程** (以 Balanced 为例):
```
BEV Queries: [B, 10000, 256] (100×100 grid)
    ↓ Decoder Layers (6层)
    ↓ Height Expand: embed_dim → embed_dim × 16
    ↓ View: [B, 256, 100, 100, 16]
    ↓ Conv3D Refine
    ↓ Upsample Head: 100×100×16 → 200×200×16 (2x2x1 上采样)
    ↓ Interpolate (trilinear)
Output: [B, 18, 200, 200, 16]
```

**问题**: 直接插值到 512×512×40 会导致模糊，且一次性生成大尺度特征图显存消耗极大。

---

## 3. 修改方案设计

### 核心策略: **Target/2 延迟上采样 + 通道递减**

**设计理念**:
1. **保持 BEV Query 尺寸不变**: 不增加 Transformer 计算量
2. **渐进式 3D 上采样**: 避免一次性生成 512×512×40 特征图
3. **Target/2 策略**: 
   - 先上采样到目标尺寸的一半 (256×256×20)
   - 使用 `nn.Upsample` (Trilinear) 确保精确对齐到中间尺寸
   - 最后一步使用 **ConvTranspose3d** (2x) 进行可学习的上采样到最终尺寸 (512×512×40)
4. **通道递减**: 256 → 128 → 64 → 32，大幅减少显存占用

### 3.1 修改后的解码流程

**新流程** (Balanced 版本):
```
BEV Queries: [B, 10000, 256] (100×100 grid) ← 不变
    ↓ Decoder Layers (6层) ← 不变
    ↓ Height Expand: embed_dim → embed_dim × 16 ← 不变
    ↓ View: [B, 256, 100, 100, 16] ← 不变
    ↓ Conv3D Refine (256 dim)
    ↓ Upsample Stage 1: 100×100×16 → 200×200×20 (ConvTranspose3d 2x, Z调整)
    ↓ Interpolate: 200×200×20 → 256×256×20 (Trilinear) ⭐ 确保对齐到 Target/2
    ↓ Upsample Stage 2: 256×256×20 → 512×512×40 (ConvTranspose3d 2x) ⭐ 最终细节恢复
    ↓ Final Conv3d: 32 dim → 18 dim
Output: [B, 18, 512, 512, 40]
```

**关键优化**:
- **Stage 1**: 尽可能使用 2x ConvTranspose3d 接近 Target/2
- **Align Stage**: 使用插值强制对齐到 Target/2 (256×256×20)
- **Stage 2**: 最终 2x 上采样，确保高频细节
- **参数优化**: 每阶段通道数递减 (256 → 128 → 64 → 32)

## 4. 详细修改方案

### 4.1 Decoder 模块修改

#### 文件: `models/transformer_occ/decoder.py`

**修改点 1: BalancedDecoder._build_upsample_head()**

```python
    def _build_upsample_head(self, embed_dim, num_classes, start_size, target_size):
        """
        构建渐进式上采样头 - Target/2 策略
        
        策略:
        1. 目标对齐到 Target/2 (256x256x20)
        2. 使用 ConvTranspose3d 接近 Target/2
        3. 使用 nn.Upsample 精确对齐 Target/2
        4. 最后使用 ConvTranspose3d 2x 上采样到 Target
        """
        layers = []
        curr_dim = embed_dim
        curr_size = list(start_size)
        
        # 检查是否可以进行最终的 2x 上采样
        can_final_2x = (target_size[0] % 2 == 0 and 
                        target_size[1] % 2 == 0 and 
                        target_size[2] % 2 == 0)
        
        # 确定中间目标尺寸 (Target 或 Target/2)
        pre_target = list(target_size)
        if can_final_2x:
            pre_target = [t // 2 for t in target_size]
            
        # Phase 1: 逼近 pre_target
        while (curr_size[0] < pre_target[0] or 
               curr_size[1] < pre_target[1] or 
               curr_size[2] < pre_target[2]):
               
            # 只有当翻倍后不超过 pre_target太多时才翻倍 (这里允许略微超过，后续插值回来，或者严格控制)
            # 策略：如果当前尺寸 * 2 <= pre_target * 1.5，则翻倍。
            # 简单起见：只要小于 pre_target 就翻倍，最后插值
            
            sx = 2 if curr_size[0] < pre_target[0] else 1
            sy = 2 if curr_size[1] < pre_target[1] else 1
            sz = 2 if curr_size[2] < pre_target[2] else 1
            
            if sx == 1 and sy == 1 and sz == 1:
                break
                
            next_dim = max(curr_dim // 2, 32)
            
            layers.extend([
                nn.ConvTranspose3d(
                    curr_dim, next_dim, 
                    kernel_size=(sx, sy, sz), 
                    stride=(sx, sy, sz)
                ),
                nn.BatchNorm3d(next_dim),
                nn.ReLU(inplace=True)
            ])
            
            curr_dim = next_dim
            curr_size[0] *= sx
            curr_size[1] *= sy
            curr_size[2] *= sz
            
        # Phase 2: 精确对齐 pre_target (Trilinear Interpolation)
        # 如果尺寸不匹配，强制插值
        if curr_size != pre_target:
            layers.append(nn.Upsample(size=tuple(pre_target), mode='trilinear', align_corners=False))
            curr_size = pre_target
            
        # Phase 3: 最终 2x 上采样 (如果适用)
        if can_final_2x:
            next_dim = max(curr_dim // 2, 32)
            layers.extend([
                nn.ConvTranspose3d(
                    curr_dim, next_dim,
                    kernel_size=2,
                    stride=2
                ),
                nn.BatchNorm3d(next_dim),
                nn.ReLU(inplace=True)
            ])
            curr_dim = next_dim
        
        # 最后的分类头
        layers.append(nn.Conv3d(curr_dim, num_classes, kernel_size=1))
        
        return nn.Sequential(*layers)
```

**修改点 2: BalancedDecoder.forward()**

移除 `forward` 函数末尾的 `F.interpolate`，因为 `upsample_head` 已经保证了输出尺寸正确。

```python
        # Upsample to target size
        x = self.upsample_head(x)  # [B, 18, 512, 512, 40]
        
        return x
```

## 5. 显存影响分析

**显存优化**:
1. **通道压缩**: 最终输出层前通道数降至 32 (原方案可能保持 64 或更高)。
2. **Target/2 策略**: 大部分计算在 256×256×20 (131万体素) 下进行，只有最后一层转为 512×512×40 (1048万体素)。
3. **延迟物化**: 避免在网络中间层生成全尺寸特征图。

**预计显存增量 (BS=1)**:
- **Balanced**: +1.5 ~ 2.0 GB
- **Nano/Mini**: +1.0 ~ 1.5 GB
- **Standard**: +2.0 GB (建议 24GB 显存)
