## 7. 关键问题检查

### ✅ 已解决的问题

#### 1. 语义激光雷达全0问题 ✅

**之前问题** (使用 64线语义激光雷达):
- 采集的占用网格数据全为 0
- 原因: 64线 × 40° FOV = 0.625° 间距,在 50m 处产生 0.55m 间隙
- 小物体 (< 0.5m) 在扫描线之间被遗漏

**当前方案** (深度相机 + Ground Truth Bounding Box):
- ✅ 非空体素率: 40.49% (4,245,785 / 10,485,760)
- ✅ 使用 CARLA Actor 完整 Bounding Box
- ✅ 8方向深度相机提供遮挡信息
- ✅ 保守光栅化算法确保小物体不被遗漏

#### 2. Label 17 语义冲突 ✅

**之前问题**:
- Label 17 被定义为 "free" (与 Label 0 重复)
- 无法表示 "通用障碍物" (general_object)

**已修复** ([occupancy_config.py](d:/code/carla/occnetv3_data_generator/config/occupancy_config.py#L46)):
```python
# 修改前
17: 'free',  # 错误: 与 Label 0 重复

# 修改后
17: 'general_object',  # 正确: 符合 nuScenes 标准
```

#### 3. Actor 类型映射不完整 ✅

**之前问题**:
- 只有简单的 CARLA_TO_OCCUPANCY 映射
- 所有车辆都被映射到 "car" (Label 4)
- 无法区分 bus/truck/motorcycle/bicycle

**已修复** ([actor_occupancy_mapping.py](d:/code/carla/occnetv3_data_generator/config/actor_occupancy_mapping.py)):
- ✅ 复制了 [dense_occupancy_collection](d:/code/carla/dense_occupancy_collection) 的完整映射表
- ✅ 1对多映射: 100+ 种 Actor type_id
- ✅ 优先级: type_id 精确匹配 → semantic_tags 兜底 → default
- ✅ 示例:
  - `vehicle.tesla.cybertruck` → Label 10 (truck)
  - `vehicle.volkswagen.t2` → Label 3 (bus)
  - `vehicle.harley-davidson.low_rider` → Label 6 (motorcycle)

### ⚠️ 当前警告

#### 1. 行人类别缺失

**问题**: Label 7 (pedestrian) 在数据集中未出现

**原因**: 当前采集场景 (Town10HD,10帧) 中没有生成行人

**建议**:
1. 使用 `spawn_npc.py -w 50` 生成行人
2. 或切换到有行人的地图 (Town01, Town03)
3. 或增加采集帧数以覆盖更多场景

#### 2. 相机标定格式差异

**问题**: 标定数据存储为 JSON 字典,而非 per-frame NPZ 数组

**影响**: [occ_network](d:/code/carla/occ_network) DataLoader 期望 NumPy 数组

**解决方案**: 在 DataLoader 中添加转换逻辑:
```python
# 伪代码
import json
with open('calibration/intrinsics.json') as f:
    intrinsics_dict = json.load(f)

# 转换为 NumPy 数组
intrinsics = np.zeros((8, 3, 3), dtype=np.float32)
for i, cam_id in enumerate(['cam_0', ..., 'cam_7']):
    K = intrinsics_dict[cam_id]
    intrinsics[i] = np.array([
        [K['fx'], 0, K['cx']],
        [0, K['fy'], K['cy']],
        [0, 0, 1]
    ])
```

    1.0,   # 15: manmade
