## 1. 两个方案的核心差异

|------|----------------------------------------|---------------------------------------|

## 2. 激光雷达方案的根本性问题

### 2.1 线束间隔导致的遗漏

**问题描述**:
- 64线激光雷达垂直 FOV 40° (上15°, 下-25°)
- 垂直角度分辨率: 40° / 64 = **0.625° ≈ 每线间隔**
- 在 50 米处,线束间隔约 **0.55 米**
- **小于 0.5 米的物体** (交通锥、杆子、行人腿部) 会被漏扫

**数学证明**:
```
距离 d = 50m
垂直角度间隔 Δθ = 0.625°
线束间隔 Δh = d × tan(Δθ) = 50 × tan(0.625°) ≈ 0.545m
```

**实际影响**:
- 交通锥 (高度 ~0.5m): 可能只扫到 1-2 个点或完全遗漏
- 交通标志杆 (直径 ~0.1m): 高概率遗漏
- 行人 (1.7m 高): 可能只扫到 3-4 层,躯干和腿部细节丢失
- 栅栏/护栏 (细长): 大量遗漏

### 2.2 当前生成结果验证

**实验结果**:
```python
# 生成的 occupancy 数据检查
occupancy = np.load('dataset_occnet_v3_test/occupancy/scene_0000_frame_0000.npy')
# Shape: (512, 512, 40) ✅
# Dtype: uint8 ✅
# Non-zero: 0 ❌  <- 关键问题!
# Unique values: [0] ❌  <- 全部为 empty!
```

**原因分析**:
1. **激光雷达未击中任何物体**: 车辆在空旷区域,或激光雷达配置错误
2. **坐标转换错误**: 世界坐标系 → Ego 坐标系转换有问题
3. **体素索引计算错误**: 点云投影到体素网格的算法有 bug
4. **激光雷达根本没有工作**: 传感器未正确初始化

### 2.3 为什么深度相机方案更可靠

**深度相机优势**:
1. **像素级密度**: 每个像素对应一个深度值,无间隙
2. **CubeMap 全覆盖**: 6个方向确保 360° 无死角
3. **Ground Truth 结合**: 先用 Actor Bounding Box 生成完整占用,再用深度图过滤可见性
4. **保守光栅化**: 算法确保细小物体被正确填充
5. **实例补全**: 即使只看到车辆一部分,整辆车都会被标记为可见

```python
def get_occupancy_label_from_actor(actor):
    # 1. 优先: type_id 精确匹配 (如 'vehicle.tesla.cybertruck' → 10)
    label = get_occupancy_label_from_type_id(actor.type_id)
    if label is not None:
        return label

    # 2. 兜底: semantic_tags (CityObjectLabel)
    if hasattr(actor, 'semantic_tags'):
        for sem_tag in actor.semantic_tags:
            if sem_tag in CITY_OBJECT_MAPPING:
                return CITY_OBJECT_MAPPING[sem_tag]

    # 3. 最终兜底: general_object (17)
    return 17
```
