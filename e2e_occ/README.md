# E2E-OccNet: 端到端3D体素网络

## 网络架构

```
输入: 8相机 RAW [B, 8, 1, 960, 1280]
       ↓
┌─────────────────────────────────────────┐
│ RAW Embed (RGGB 2x2拆分 + 共享编码器)   │
│ - RGGB拆分: [B,8,1,960,1280] → [B,8,4,480,640]
│ - 卷积stem: 4通道 → 256通道, 16x下采样
│ - 输出: [B, 8, 256, 60, 80]
└─────────────────────────────────────────┘
       ↓
┌─────────────────────────────────────────┐
│ Image Encoder (窗口注意力, 4层)         │
│ - 输入: [B, 8, 256, 60, 80]
│ - 窗口自注意力 + FFN
│ - 输出: [B, 8, 256, 60, 80]
└─────────────────────────────────────────┘
       ↓
┌─────────────────────────────────────────┐
│ Coarse Decoder (50×50×8 = 20K queries)  │
│ - 可学习3D Query + 位置编码
│ - Deformable Cross-Attn (每query采样4点)
│ - 3层解码
│ - 输出: [B, 256, 50, 50, 8]
└─────────────────────────────────────────┘
       ↓ 三线性上采样
┌─────────────────────────────────────────┐
│ Fine Decoder (100×100×16 = 160K queries)│
│ - Deformable Cross-Attn 精细化
│ - 3层解码
│ - 输出: [B, 256, 100, 100, 16]
└─────────────────────────────────────────┘
       ↓
┌─────────────────────────────────────────┐
│ Voxel Head (转置卷积上采样)             │
│ - 100→200→400 (4x上采样)
│ - 16→32 (2x上采样)
│ - 输出: [B, 18, 400, 400, 32]
└─────────────────────────────────────────┘

输出: 3D语义体素 [B, 18, 400, 400, 32]
      (体素分辨率 0.2m, 覆盖 80m×80m×6.4m)
```

## 关键设计

1. **RGGB RAW嵌入**: 2×2步长2拆分Bayer模式,8相机共享编码器
2. **可变形注意力**: 每Query只采样4个点,计算量从30亿降到500万
3. **粗到细策略**: 20K→160K queries,逐步精细化
4. **显存优化**: batch=1时约12GB,4090可训练

## 文件列表

```
e2e_occ/
├── config.py              # 配置
├── position_encoding.py   # 位置编码
├── raw_embed.py           # RAW嵌入 (RGGB处理)
├── image_encoder.py       # 图像编码器
├── deformable_attention.py# 可变形注意力
├── occ_decoder.py         # Occupancy解码器
├── voxel_head.py          # 体素预测头
├── e2e_occ_net.py         # 主网络
├── loss.py                # 损失函数
├── dataset.py             # 数据集
├── train.py               # 训练脚本
├── inference.py           # 推理脚本
└── test.py                # 测试脚本
```

## 使用方法

```bash
# 测试网络
python test.py

# 训练
python train.py --data_root ./data --batch_size 1

# 推理
python inference.py --checkpoint checkpoints/best.pth --input sample.npz
```

## 计算量分析

| 模块 | Query数 | 采样点 | 计算量 |
|------|---------|--------|--------|
| Coarse Cross-Attn | 20,000 | 8×4=32 | 640K |
| Fine Cross-Attn | 160,000 | 8×4=32 | 5.12M |
| **总计** | - | - | **~6M** |

对比全注意力: 160K × (8×60×80) = 7.7B → **节省1000倍**
