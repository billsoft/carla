## 可变形注意力详解

```
┌────────────────────────────────────────────────────────────────────────────┐
│              Deformable Cross-Attention 工作原理                           │
├────────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│  传统 Cross-Attention:                                                     │
│  ─────────────────────                                                     │
│                                                                            │
│  Query (3D体素位置)          Key/Value (图像特征)                          │
│       ↓                           ↓                                        │
│  [20000, 256]              [8×60×80, 256] = [38400, 256]                   │
│       ↓                           ↓                                        │
│       └─────────────┬─────────────┘                                        │
│                     ↓                                                      │
│            Attention [20000, 38400] = 768M 参数!                           │
│                     ↓                                                      │
│            显存爆炸! 无法训练                                              │
│                                                                            │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                            │
│  Deformable Cross-Attention (本网络使用):                                  │
│  ─────────────────────────────────────────                                 │
│                                                                            │
│  对于每个 3D Query:                                                        │
│                                                                            │
│  Step 1: 预测采样偏移                                                      │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Query [256]                                                        │   │
│  │      ↓ Linear                                                       │   │
│  │  offset [8相机 × 4点 × 2坐标] = [64]                                │   │
│  │                                                                     │   │
│  │  例: Query表示(10m, 5m, 1m)位置                                     │   │
│  │      预测: cam0在(0.52,0.48), cam1在(0.31,0.62)...采样             │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                            │
│  Step 2: 双线性采样                                                        │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │     相机0特征图 [256, 60, 80]                                       │   │
│  │    ┌─────────────────────────────┐                                  │   │
│  │    │                             │                                  │   │
│  │    │      ×  ×  ×  ×             │  ← 只采样4个点!                  │   │
│  │    │                             │                                  │   │
│  │    │                             │                                  │   │
│  │    └─────────────────────────────┘                                  │   │
│  │                                                                     │   │
│  │    grid_sample(特征图, 采样坐标) → [4, 256]                         │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                            │
│  Step 3: 加权聚合                                                          │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Query [256]                                                        │   │
│  │      ↓ Linear + Softmax                                             │   │
│  │  weights [8相机 × 4点] = [32]                                       │   │
│  │                                                                     │   │
│  │  output = Σ(weight × sampled_feature)                               │   │
│  │         = w0×f0 + w1×f1 + ... + w31×f31                            │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                            │
│  计算量对比:                                                               │
│  ─────────────                                                             │
│  传统: 20000 × 38400 = 768,000,000                                        │
│  可变形: 20000 × 32 = 640,000                                              │
│  节省: 1200倍!                                                             │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
```

## 回答你的问题

**Q1: 查询时除了交叉注意力还要可变形才能节省?**

是的! 必须用可变形注意力:
- 普通Cross-Attention: 160K × 38K = 6.1B 计算量
- Deformable: 160K × 32 = 5.1M 计算量
- 节省 1200 倍!

**Q2: RAW图像能共用编码器?**

是的! 本设计中:
- 8个相机共享同一个 `RAWPatchEmbed`
- 用 `CameraEmbedding` 区分不同相机
- 参数量减少 8 倍

**Q3: RGGB 2×2步长2怎么实现?**

```python
class RGGBUnpack(nn.Module):
    def forward(self, x):  # x: [B,N,1,H,W]
        r  = x[:, :, :, 0::2, 0::2]  # 红
        g1 = x[:, :, :, 0::2, 1::2]  # 绿1
        g2 = x[:, :, :, 1::2, 0::2]  # 绿2
        b  = x[:, :, :, 1::2, 1::2]  # 蓝
        return torch.cat([r, g1, g2, b], dim=2)  # [B,N,4,H/2,W/2]
```

这样把 Bayer 模式的 RAW 转成 4 通道，尺寸减半。
