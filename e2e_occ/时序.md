# E2E-OccNet 时序融合模块开发计划

> 目标：在潜空间实现多帧特征融合，隐式时序记忆，类RNN效果

---

## 一、当前架构 vs 目标架构

### 1.1 当前架构（无时序）

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  单帧处理，帧与帧之间完全独立                                       │
│                                                                     │
│  t=0: [8×图像] → PatchEmbed → Encoder → Decoder → [输出]           │
│  t=1: [8×图像] → PatchEmbed → Encoder → Decoder → [输出]           │
│  t=2: [8×图像] → PatchEmbed → Encoder → Decoder → [输出]           │
│       ↑                                                             │
│       └── 每帧独立处理，没有历史信息传递                            │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 1.2 目标架构（时序融合）

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  多帧特征在潜空间拼接，做跨帧注意力                                 │
│                                                                     │
│  t=0: [8×图像] → PatchEmbed → Encoder → [特征F0]                   │
│                                              ↓                      │
│  t=1: [8×图像] → PatchEmbed → Encoder → [特征F1]                   │
│                                              ↓                      │
│                                    ┌─────────────────┐              │
│                                    │ Temporal Fusion │              │
│                                    │                 │              │
│                                    │ [F0, F1] 拼接   │              │
│                                    │     ↓           │              │
│                                    │ 跨帧注意力      │              │
│                                    │     ↓           │              │
│                                    │ Memory更新      │              │
│                                    └────────┬────────┘              │
│                                             ↓                       │
│                                         Decoder → [输出]            │
│                                                                     │
│  t=2: [8×图像] → Encoder → [特征F2] + Memory → Fusion → ...       │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 二、核心模块设计

### 2.1 TemporalFusion 模块架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                    TemporalFusion 模块详细设计                      │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  输入:                                                              │
│  ├── current_feat: [B, N, C, H, W]  当前帧特征                     │
│  ├── memory_feat:  [B, N, C, H, W]  历史记忆特征 (可学习初始化)    │
│  └── ego_motion:   [B, 4, 4]        自车运动矩阵 (可选)            │
│                                                                     │
│  ═══════════════════════════════════════════════════════════════    │
│                                                                     │
│  处理流程:                                                          │
│                                                                     │
│  Step 1: 特征对齐 (如果有ego_motion)                                │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │  # 把历史特征warp到当前坐标系                                │    │
│  │  memory_aligned = spatial_transform(memory_feat, ego_motion) │    │
│  │                                                              │    │
│  │  # 或者更简单：不对齐，让网络自己学                          │    │
│  │  memory_aligned = memory_feat                                │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                     │
│  Step 2: 特征拼接                                                   │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │  # 方案A: 沿batch维度拼接 (简单)                            │    │
│  │  concat_feat = torch.cat([current, memory], dim=0)          │    │
│  │  # shape: [2B, N, C, H, W]                                  │    │
│  │                                                              │    │
│  │  # 方案B: 沿时间维度拼接 (推荐)                             │    │
│  │  concat_feat = torch.stack([memory, current], dim=1)        │    │
│  │  # shape: [B, 2, N, C, H, W] → [B, 2*N, C, H, W]           │    │
│  │                                                              │    │
│  │  # 方案C: 沿通道维度拼接                                    │    │
│  │  concat_feat = torch.cat([current, memory], dim=2)          │    │
│  │  # shape: [B, N, 2C, H, W]                                  │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                     │
│  Step 3: 跨帧注意力 (核心!)                                         │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │  选项1: 全局Self-Attention                                   │    │
│  │  ─────────────────────────                                   │    │
│  │  # 把所有位置flatten，做全连接注意力                        │    │
│  │  # 计算量大，但效果好                                       │    │
│  │  feat_flat = concat_feat.flatten(2)  # [B, 2N, C*H*W]       │    │
│  │  attn_out = self_attention(feat_flat)                       │    │
│  │                                                              │    │
│  │  选项2: Deformable Cross-Attention (推荐!)                   │    │
│  │  ─────────────────────────────────                           │    │
│  │  # 当前帧query，历史帧key/value                             │    │
│  │  # 可学习的采样点，高效                                     │    │
│  │  fused = deformable_attn(                                   │    │
│  │      query=current_feat,                                    │    │
│  │      key=memory_feat,                                       │    │
│  │      value=memory_feat                                      │    │
│  │  )                                                          │    │
│  │                                                              │    │
│  │  选项3: 窗口注意力 (节省显存)                                │    │
│  │  ─────────────────────────                                   │    │
│  │  # 只在局部窗口内做跨帧注意力                               │    │
│  │  fused = window_temporal_attn(current, memory, window=7)    │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                     │
│  Step 4: 记忆更新 (类GRU门控)                                       │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │  # 学习"记住多少旧信息，接受多少新信息"                     │    │
│  │                                                              │    │
│  │  gate = sigmoid(W_gate @ concat([current, memory]))         │    │
│  │  new_memory = gate * fused + (1 - gate) * memory            │    │
│  │                                                              │    │
│  │  # 或者更简单：直接用融合后的特征作为新记忆                  │    │
│  │  new_memory = fused                                         │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                     │
│  输出:                                                              │
│  ├── fused_feat:  [B, N, C, H, W]  融合后的特征 (送入Decoder)      │
│  └── new_memory:  [B, N, C, H, W]  更新后的记忆 (下一帧使用)       │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 2.2 推荐方案：BEV空间时序融合

```
┌─────────────────────────────────────────────────────────────────────┐
│                    BEV空间时序融合 (更高效)                         │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  思路: 不在图像空间融合，而是在BEV空间融合                         │
│                                                                     │
│  为什么更好?                                                        │
│  • 图像空间: [B, 8, C, 60, 80] = 8个视角，位置对应不上             │
│  • BEV空间:  [B, C, 200, 200] = 统一的鸟瞰图，位置直接对应         │
│                                                                     │
│  ═══════════════════════════════════════════════════════════════    │
│                                                                     │
│  修改后的架构:                                                      │
│                                                                     │
│  [8×图像] → Encoder → [图像特征]                                   │
│                            ↓                                        │
│                      Coarse Decoder                                 │
│                            ↓                                        │
│                    [BEV特征 25×25×8]                                │
│                            ↓                                        │
│               ┌───────────────────────┐                             │
│               │   Temporal Fusion     │  ← 在BEV空间做时序融合     │
│               │   (BEV Memory)        │                             │
│               └───────────────────────┘                             │
│                            ↓                                        │
│                      Fine Decoder                                   │
│                            ↓                                        │
│                    [输出 400×400×32]                                │
│                                                                     │
│  优点:                                                              │
│  • 空间位置天然对齐                                                 │
│  • 可以用ego_motion做精确warp                                       │
│  • 显存开销小 (BEV比8张图小)                                       │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

```python
# 伪代码结构

class TemporalDeformableAttention(nn.Module):
    """
    时序可变形注意力
    当前帧query，历史帧key/value
    """
    def __init__(self, dim, num_heads, num_points=4):
        self.sampling_offsets = nn.Linear(dim, num_heads * num_points * 2)
        self.attention_weights = nn.Linear(dim, num_heads * num_points)
        self.value_proj = nn.Linear(dim, dim)
        self.output_proj = nn.Linear(dim, dim)
    
    def forward(self, query, memory):
        # query: [B, Q, C] 当前帧
        # memory: [B, Q, C] 历史记忆
        # 输出: [B, Q, C] 融合后特征
        pass


class GRUGate(nn.Module):
    """
    GRU风格的门控更新
    控制记住多少旧信息，接受多少新信息
    """
    def __init__(self, dim):
        self.reset_gate = nn.Linear(dim * 2, dim)
        self.update_gate = nn.Linear(dim * 2, dim)
        self.candidate = nn.Linear(dim * 2, dim)
    
    def forward(self, current, memory):
        # 输出: 更新后的记忆
        pass


class TemporalFusionModule(nn.Module):
    """
    完整的时序融合模块
    """
    def __init__(self, config):
        self.temporal_attn = TemporalDeformableAttention(...)
        self.gate = GRUGate(...)
        self.norm = nn.LayerNorm(...)
        
        # 可学习的初始记忆
        self.init_memory = nn.Parameter(torch.zeros(1, num_queries, dim))
    
    def forward(self, current_feat, memory=None):
        """
        current_feat: [B, Q, C] 当前帧特征
        memory: [B, Q, C] 历史记忆，首帧为None
        """
        if memory is None:
            memory = self.init_memory.expand(B, -1, -1)
        
        # 1. 跨帧注意力
        fused = self.temporal_attn(current_feat, memory)
        fused = current_feat + fused  # 残差连接
        
        # 2. 门控更新
        new_memory = self.gate(fused, memory)
        
        return fused, new_memory
```

```python
class E2EOccNet(nn.Module):
    def __init__(self, config):
        # ... 原有模块 ...
        
        # 新增时序融合模块
        if config.use_temporal:
            self.temporal_fusion = TemporalFusionModule(config)
    
    def forward(self, images, intrinsics=None, extrinsics=None, memory=None):
        """
        新增参数:
        - memory: 历史记忆，首帧为None
        
        新增返回:
        - new_memory: 更新后的记忆
        """
        # 1. 图像编码
        feats = self.patch_embed(images)
        feats = self.encoder(feats, intrinsics, extrinsics)
        
        # 2. 时序融合 (如果在图像空间)
        if self.config.use_temporal and self.config.temporal_fusion_type == "image":
            feats, new_memory = self.temporal_fusion(feats, memory)
        
        # 3. 3D解码
        voxel_feats = self.decoder(feats, intrinsics, extrinsics)
        
        # 或者在BEV空间融合 (在decoder内部)
        
        # 4. 输出
        logits = self.head(voxel_feats)
        
        return {
            'semantic': logits,
            'memory': new_memory if self.config.use_temporal else None
        }
```

### 3.5 修改文件：train.py

```python
def train_epoch(model, loader, ...):
    for batch in loader:
        images = batch['images']  # [B, T, N, C, H, W]
        voxels = batch['voxels']  # [B, T, X, Y, Z]
        
        T = images.shape[1]
        memory = None
        total_loss = 0
        
        # 逐帧处理，传递memory
        for t in range(T):
            outputs = model(
                images[:, t],           # 当前帧图像
                intrinsics,
                extrinsics[:, t],
                memory=memory           # 传入历史记忆
            )
            
            memory = outputs['memory']  # 更新记忆
            
            # 计算当前帧loss
            loss_t = criterion(outputs['semantic'], voxels[:, t])
            total_loss += loss_t
        
        # 反向传播 (梯度可以流过整个序列)
        total_loss.backward()
```

## 五、关键设计决策

### 5.1 融合位置选择

| 融合位置 | 优点 | 缺点 | 推荐 |
|----------|------|------|------|
| ImageEncoder后 | 保留最多信息 | 8个视角难对齐 | ⚠️ |
| Coarse Decoder后 | BEV空间，易对齐 | 分辨率低(25×25) | ✅ 推荐 |
| Fine Decoder后 | 分辨率高 | 显存开销大 | ❌ |

**推荐：在Coarse阶段后、Fine阶段前融合**

### 5.2 注意力类型选择

| 类型 | 计算量 | 显存 | 效果 | 推荐 |
|------|--------|------|------|------|
| 全局Self-Attention | O(N²) | 高 | 最好 | ❌ N太大 |
| Deformable Attention | O(N×K) | 低 | 很好 | ✅ 推荐 |
| 窗口Attention | O(N×W²) | 中 | 好 | ⚠️ 备选 |

**推荐：Deformable Attention，每个位置只采样4-8个历史位置**

### 5.3 记忆更新方式

| 方式 | 描述 | 复杂度 | 推荐 |
|------|------|--------|------|
| 直接替换 | new_memory = fused | 最简单 | ⚠️ 可能遗忘 |
| 加权平均 | new = α*fused + (1-α)*old | 简单 | ⚠️ α难调 |
| GRU门控 | 学习的门控更新 | 中等 | ✅ 推荐 |
| LSTM门控 | 更复杂的门控 | 复杂 | ❌ 过度 |

**推荐：GRU风格门控，学习"记住多少、更新多少"**

## 七、代码模板

### temporal_fusion.py 完整模板

```python
"""
时序融合模块
实现多帧特征在潜空间的融合，类RNN隐式时序记忆
"""

import torch
import torch.nn as nn
import torch.nn.functional as F


class TemporalDeformableAttention(nn.Module):
    """
    时序可变形注意力
    当前帧作为Query，历史记忆作为Key/Value
    学习从历史中采样哪些位置
    """
    
    def __init__(self, dim, num_heads=8, num_points=4, dropout=0.1):
        super().__init__()
        self.dim = dim
        self.num_heads = num_heads
        self.num_points = num_points
        self.head_dim = dim // num_heads
        
        # 采样偏移预测
        self.sampling_offsets = nn.Linear(dim, num_heads * num_points * 3)  # 3D偏移
        
        # 注意力权重预测
        self.attention_weights = nn.Linear(dim, num_heads * num_points)
        
        # Value投影
        self.value_proj = nn.Linear(dim, dim)
        
        # 输出投影
        self.output_proj = nn.Linear(dim, dim)
        
        self.dropout = nn.Dropout(dropout)
        
        self._init_weights()
    
    def _init_weights(self):
        nn.init.constant_(self.sampling_offsets.weight, 0.0)
        nn.init.constant_(self.sampling_offsets.bias, 0.0)
        nn.init.xavier_uniform_(self.attention_weights.weight)
        nn.init.constant_(self.attention_weights.bias, 0.0)
    
    def forward(self, query, memory, query_pos=None):
        """
        query:  [B, Q, C] 当前帧特征 (Q = num_queries)
        memory: [B, Q, C] 历史记忆特征
        query_pos: [B, Q, 3] 查询点的3D位置 (可选，用于位置编码)
        
        返回: [B, Q, C] 融合后特征
        """
        B, Q, C = query.shape
        
        # 1. 预测采样偏移
        offsets = self.sampling_offsets(query)  # [B, Q, num_heads * num_points * 3]
        offsets = offsets.view(B, Q, self.num_heads, self.num_points, 3)
        offsets = offsets.tanh() * 0.5  # 限制偏移范围
        
        # 2. 预测注意力权重
        attn_weights = self.attention_weights(query)  # [B, Q, num_heads * num_points]
        attn_weights = attn_weights.view(B, Q, self.num_heads, self.num_points)
        attn_weights = F.softmax(attn_weights, dim=-1)
        
        # 3. 投影Value
        value = self.value_proj(memory)  # [B, Q, C]
        value = value.view(B, Q, self.num_heads, self.head_dim)
        
        # 4. 简化实现：直接从memory的相邻位置采样
        # (完整实现需要grid_sample，这里用简化版本)
        output = torch.zeros(B, Q, self.num_heads, self.head_dim, device=query.device)
        
        for p in range(self.num_points):
            # 对每个采样点，从memory中取值并加权
            # 简化：直接用memory的值，实际应该根据offsets采样
            sampled = value  # [B, Q, num_heads, head_dim]
            weight = attn_weights[..., p:p+1]  # [B, Q, num_heads, 1]
            output = output + sampled * weight
        
        # 5. 合并多头
        output = output.view(B, Q, C)
        output = self.output_proj(output)
        
        return self.dropout(output)


class GRUGate(nn.Module):
    """
    GRU风格的门控更新
    学习"记住多少旧信息，接受多少新信息"
    """
    
    def __init__(self, dim):
        super().__init__()
        self.dim = dim
        
        # 更新门: 决定多少新信息流入
        self.update_gate = nn.Sequential(
            nn.Linear(dim * 2, dim),
            nn.Sigmoid()
        )
        
        # 重置门: 决定多少旧记忆被遗忘
        self.reset_gate = nn.Sequential(
            nn.Linear(dim * 2, dim),
            nn.Sigmoid()
        )
        
        # 候选记忆
        self.candidate = nn.Sequential(
            nn.Linear(dim * 2, dim),
            nn.Tanh()
        )
    
    def forward(self, current, memory):
        """
        current: [B, Q, C] 当前帧特征
        memory:  [B, Q, C] 历史记忆
        
        返回: [B, Q, C] 更新后的记忆
        """
        concat = torch.cat([current, memory], dim=-1)
        
        # 计算门控
        z = self.update_gate(concat)
        r = self.reset_gate(concat)
        
        # 候选记忆 (用重置门控制旧记忆的影响)
        concat_reset = torch.cat([current, r * memory], dim=-1)
        h_candidate = self.candidate(concat_reset)
        
        # 最终记忆: 旧记忆 + 更新门控制的新信息
        new_memory = (1 - z) * memory + z * h_candidate
        
        return new_memory


class TemporalFusionModule(nn.Module):
    """
    完整的时序融合模块
    
    流程:
    1. 当前帧特征 + 历史记忆 → 跨帧注意力
    2. 门控更新记忆
    3. 返回融合特征和新记忆
    """
    
    def __init__(self, dim, num_heads=8, num_points=4, dropout=0.1):
        super().__init__()
        
        # 时序注意力
        self.temporal_attn = TemporalDeformableAttention(
            dim, num_heads, num_points, dropout
        )
        
        # 门控更新
        self.gate = GRUGate(dim)
        
        # 层归一化
        self.norm1 = nn.LayerNorm(dim)
        self.norm2 = nn.LayerNorm(dim)
        
        # FFN
        self.ffn = nn.Sequential(
            nn.Linear(dim, dim * 4),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(dim * 4, dim),
            nn.Dropout(dropout)
        )
        
        # 可学习的初始记忆
        self.init_memory = None  # 会在第一次forward时初始化
    
    def _init_memory(self, B, Q, C, device):
        """初始化记忆为零向量"""
        return torch.zeros(B, Q, C, device=device)
    
    def forward(self, current_feat, memory=None):
        """
        current_feat: [B, Q, C] 当前帧特征
        memory: [B, Q, C] 历史记忆，首帧为None
        
        返回:
        - fused_feat: [B, Q, C] 融合后的特征
        - new_memory: [B, Q, C] 更新后的记忆
        """
        B, Q, C = current_feat.shape
        
        # 首帧：初始化记忆
        if memory is None:
            memory = self._init_memory(B, Q, C, current_feat.device)
        
        # 1. 时序注意力
        attn_out = self.temporal_attn(
            self.norm1(current_feat),
            self.norm1(memory)
        )
        fused = current_feat + attn_out  # 残差连接
        
        # 2. FFN
        fused = fused + self.ffn(self.norm2(fused))
        
        # 3. 门控更新记忆
        new_memory = self.gate(fused, memory)
        
        return fused, new_memory
```
