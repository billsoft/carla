### 问题 2: 后置摄像头输出全黑图像

**原始现象**:
```
cam_rear: (960, 1280, 3) uint8
  范围: [0, 0]  ← 完全黑色
```

**根本原因**:
- 摄像头位置 `x=-1.8, z=1.0` 太靠近车身
- 镜头被车身后部遮挡

**修复方案**:
```python
# 修改前
carla.Location(x=-1.8, z=1.0)

# 修改后
carla.Location(x=-2.5, z=1.5)  # 向后和向上移动
```

**修复位置**: [collect_5_frames.py:200](scripts/collect_5_frames.py#L200)

**验证**: 需要重新运行测试确认像素范围不再是 [0, 0]

### 问题 3: 数据未保存到磁盘

**原始现象**:
- 脚本运行完成后,`dataset_output/` 目录不存在
- 所有数据仅存储在内存中 (`collected_frames` 列表)
- 程序结束后数据丢失

**根本原因**:
- 代码仅在第 296-301 行将数据 append 到列表
- 没有文件写入操作

**修复方案**:
添加了以下保存功能:

1. **相机图像保存** (PNG 格式):
```python
for cam_id, cam_data in camera_data.items():
    img = Image.fromarray(cam_data['data'])
    img_path = cameras_dir / cam_id / f"{frame_idx:06d}.png"
    img.save(img_path)
```

2. **激光雷达点云保存** (NPZ 压缩格式):
```python
lidar_path = lidar_dir / f"{frame_idx:06d}.npz"
np.savez_compressed(
    lidar_path,
    points=lidar_data['points'],
    frame=lidar_data['frame'],
    timestamp=lidar_data['timestamp']
)
```

3. **标定参数保存** (JSON 格式):
```python
calibration = {
    'cameras': {...},
    'lidar': {...},
    'dataset_info': {...}
}
with open(calibration_path, 'w', encoding='utf-8') as f:
    json.dump(calibration, f, indent=2, ensure_ascii=False)
```

**修复位置**: [collect_5_frames.py:81-90, 304-390](scripts/collect_5_frames.py)

**验证**: 需要检查 `dataset_output/town10_test/` 目录是否包含所有文件
