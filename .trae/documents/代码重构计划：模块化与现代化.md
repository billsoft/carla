# 重构计划：模块化与现代化 (Refactoring Plan)

我将对 `dense_occupancy_collection` 进行全面重构，清理旧的 LiDAR 代码，并将逻辑拆分为优雅的、可复用的模块。

## 1. 目录结构设计

新结构将更加扁平化和模块化：

```text
dense_occupancy_collection/
├── config/                  # 保持不变，清理旧配置
│   ├── occupancy_config.py  # 核心配置 (XYZ范围, 映射, 相机参数)
│   └── ...
├── core/                    # 新核心模块
│   ├── __init__.py
│   ├── scenario_manager.py  # 场景管理 (Hero, NPC spawn/destroy)
│   ├── sensor_interface.py  # 传感器基类
│   ├── rgb_suite.py         # 8相机 RGB 采集 (12bit raw/8bit)
│   ├── depth_suite.py       # 6相机 Depth 全景采集 (360°x60°)
│   ├── voxel_generator.py   # 体素生成器 (UE5 Query + Mapping)
│   └── visibility_filter.py # 可见性过滤 (Depth Mask + Instance Completion)
├── utils/                   # 工具函数
│   ├── __init__.py
│   └── data_saver.py        # 统一的数据保存接口
├── main_data_collection.py  # 新的入口脚本 (替换 collect_panorama.py)
└── ...
```

## 2. 待删除/清理的文件

以下文件包含过时逻辑，将被**删除**：
*   `processing/lidar_voxel_generator.py`: 旧版 LiDAR 体素生成。
*   `sensors/semantic_lidar_sensor.py`: 旧版语义 LiDAR 传感器。
*   `scripts/collect_panorama.py`: 被新的 `main_data_collection.py` 替代。

## 3. 核心模块重构细节

### A. `core/scenario_manager.py`
*   封装 Hero 车辆生成逻辑 (随机位置/指定位置)。
*   封装 NPC 生成逻辑 (Car, Truck, Pedestrian 比例控制)。
*   提供统一的 `destroy()` 接口清理所有 Actor。

### B. `core/rgb_suite.py`
*   管理 8 个 RGB 相机。
*   提供同步 `get_data()` 接口。
*   保留现有的 PostProcess/Gamma 设置以确保画质。

### C. `core/depth_suite.py`
*   管理 6 个深度相机 (Front, Back, Left, Right, Up, Down)。
*   配置为 Z=2.2m, 垂直 FOV 60° (±30°)。
*   提供同步 `get_data()` 接口，返回 Depth Maps 和 Camera Transforms。

### D. `core/voxel_generator.py`
*   **纯净重构**：移除所有 LiDAR 相关代码。
*   保留基于 UE5 `world.get_environment_objects()` 的静态物体查询。
*   保留基于 `world.get_actors()` 的动态物体查询。
*   保留保守光栅化 (Conservative Rasterization) 逻辑。
*   集成 Industry Mapping (CARLA -> SemanticKITTI/Occupancy)。

### E. `core/visibility_filter.py`
*   封装 Numba 加速的深度投影算法。
*   实现 **"Instance Completion"** 逻辑：只要 Actor 有一点可见，整体可见。
*   输入：Full Voxel Grid + Depth Maps。
*   输出：Filtered Voxel Grid (Masked)。

## 4. 执行步骤

1.  **创建新目录结构** (`core/`, `utils/`)。
2.  **编写核心模块**：依次实现上述 Python 文件。
3.  **编写入口脚本**：`main_data_collection.py` 串联流程。
4.  **清理旧文件**：删除废弃代码。
5.  **验证**：运行新脚本，确保生成的数据与之前一致 (RGB + Depth + Voxel)。
