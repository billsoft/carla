## 1. 概述：虚拟世界中的自动驾驶 {#概述}

### 1.1 为什么需要仿真？

真实世界的自动驾驶训练面临三大挑战：
- **成本高昂**：一辆测试车每小时成本数千美元
- **危险性高**：边缘案例（如突然冲出的行人）无法安全重现
- **数据稀缺**：罕见场景（暴雨、大雪、极端交通）难以收集

CARLA 提供的解决方案：
- ✅ **零成本重复实验**：虚拟车辆无限次碰撞也不心疼
- ✅ **可控的极端场景**：一键切换天气、时间、交通密度
- ✅ **完美的真值标注**：每个像素的语义分割、深度信息自动生成
- ✅ **加速训练**：多进程并行采集数据，比真车快100倍

### 2.2 通信机制

**两条独立通道**：

1. **RPC 通道（端口 2000）**
   - 同步请求-响应模式
   - 用于：生成车辆、设置天气、发送控制指令
   - 协议：MsgPack 序列化

2. **Streaming 通道（端口 2001）**
   - 异步高性能数据流
   - 用于：传感器数据传输（图像/点云）
   - 优化：零拷贝内存映射

#### **图像格式选择**

CARLA 支持多种图像格式，选择取决于您的需求：

| 格式 | 位深 | 压缩 | 用途 | 带宽 |
|------|------|------|------|------|
| **RAW** | 8-bit BGRA | 无 | 训练（原始数据） | 高 (7.91 MB/帧@1080p) |
| **PNG** | 8-bit RGBA | 无损 | 高质量存储 | 中 (2-4 MB/帧) |
| **JPEG** | 8-bit RGB | 有损 | 快速预览 | 低 (0.5-1 MB/帧) |

**重要提示**：CARLA 默认相机是 **8-bit**，如需 **12-bit RAW**（模拟真实车载相机），需要：

```python
# 方案 1: 使用深度相机作为 HDR 通道
depth_camera = {
    'type': 'sensor.camera.depth',
    'image_format': 'RAW',  # 32-bit float per pixel (相当于 96-bit RGB)
}

# 方案 2: 修改 CARLA 源码
# 文件: Unreal/CarlaUnreal/Plugins/Carla/Source/Carla/Sensor/SceneCaptureCamera.cpp
# 将 PF_B8G8R8A8 改为 PF_FloatRGBA (16-bit per channel)
```

**实际建议**：
- **训练阶段**：使用 8-bit RAW 已足够（神经网络对位深不敏感）
- **Sim2Real 迁移**：使用深度相机 + RGB 相机双流输入

### 4.2 关键代码：传感器数据回调

```python
import carla
import numpy as np
import queue

class SensorSuite:
    def __init__(self, world, vehicle):
        self.world = world
        self.vehicle = vehicle
        self.sensors = {}
        self.data_queue = queue.Queue()

    def spawn_cameras(self):
        """生成8个相机"""
        bp_library = self.world.get_blueprint_library()

        # 前置主相机
        cam_bp = bp_library.find('sensor.camera.rgb')
        cam_bp.set_attribute('image_size_x', '1920')
        cam_bp.set_attribute('image_size_y', '1080')
        cam_bp.set_attribute('fov', '70')
        cam_bp.set_attribute('sensor_tick', '0.033')  # 30 FPS

        cam_transform = carla.Transform(
            carla.Location(x=2.5, z=1.4),
            carla.Rotation(pitch=0.0)
        )

        camera = self.world.spawn_actor(
            cam_bp,
            cam_transform,
            attach_to=self.vehicle
        )

        # 注册回调函数
        camera.listen(lambda image: self._on_front_camera(image))
        self.sensors['front_camera'] = camera

    def _on_front_camera(self, image):
        """相机数据回调"""
        # 转换为 NumPy 数组
        array = np.frombuffer(image.raw_data, dtype=np.uint8)
        array = array.reshape((image.height, image.width, 4))  # BGRA

        # BGR → RGB
        rgb = array[:, :, [2, 1, 0]]

        # 存入队列（线程安全）
        self.data_queue.put({
            'frame': image.frame,
            'timestamp': image.timestamp,
            'data': rgb,
            'sensor': 'front_camera'
        })

    def spawn_lidar(self):
        """生成激光雷达"""
        bp = self.world.get_blueprint_library().find('sensor.lidar.ray_cast')
        bp.set_attribute('channels', '64')
        bp.set_attribute('range', '100')
        bp.set_attribute('points_per_second', '1000000')
        bp.set_attribute('rotation_frequency', '10')

        lidar = self.world.spawn_actor(
            bp,
            carla.Transform(carla.Location(z=2.4)),
            attach_to=self.vehicle
        )

        lidar.listen(lambda data: self._on_lidar(data))
        self.sensors['lidar'] = lidar

    def _on_lidar(self, data):
        """LiDAR 数据回调"""
        # 转换为 NumPy 数组 (N × 4: x, y, z, intensity)
        points = np.frombuffer(data.raw_data, dtype=np.float32)
        points = points.reshape((-1, 4))

        self.data_queue.put({
            'frame': data.frame,
            'data': points,
            'sensor': 'lidar'
        })
```

```python
class ExpertDriver:
    """使用 CARLA 自带的 Autopilot 作为专家"""

    def __init__(self, vehicle):
        self.vehicle = vehicle
        self.dataset = []

    def collect_data(self, duration_seconds=3600):
        """采集1小时的驾驶数据"""
        # 启用自动驾驶（专家）
        self.vehicle.set_autopilot(True)

        start_time = time.time()
        while time.time() - start_time < duration_seconds:
            # 获取当前控制指令（专家的决策）
            control = self.vehicle.get_control()

            # 获取传感器数据
            sensors = self.get_current_sensor_data()

            # 获取车辆状态
            velocity = self.vehicle.get_velocity()
            speed = 3.6 * np.sqrt(velocity.x**2 + velocity.y**2 + velocity.z**2)  # km/h

            # 保存为训练样本
            self.dataset.append({
                # 输入特征
                'front_camera': sensors['front_camera'],
                'left_camera': sensors['left_camera'],
                'right_camera': sensors['right_camera'],
                'lidar': sensors['lidar'],
                'speed': speed,

                # 标签（专家的控制指令）
                'steering': control.steer,      # [-1, 1]
                'throttle': control.throttle,   # [0, 1]
                'brake': control.brake,         # [0, 1]
            })

            time.sleep(0.05)  # 20 Hz 采样率

    def save_dataset(self, path):
        """保存为 HDF5 格式（高效存储）"""
        import h5py

        with h5py.File(path, 'w') as f:
            # 预分配数组
            n_samples = len(self.dataset)
            f.create_dataset('front_camera', (n_samples, 1080, 1920, 3), dtype='uint8')
            f.create_dataset('steering', (n_samples,), dtype='float32')
            f.create_dataset('throttle', (n_samples,), dtype='float32')
            f.create_dataset('brake', (n_samples,), dtype='float32')

            # 批量写入
            for i, sample in enumerate(self.dataset):
                f['front_camera'][i] = sample['front_camera']
                f['steering'][i] = sample['steering']
                f['throttle'][i] = sample['throttle']
                f['brake'][i] = sample['brake']
```

#### **DAgger 算法（交互式改进）**

解决模型漂移问题：

```python
def dagger_iteration(model, expert, n_episodes=10):
    """
    DAgger: Dataset Aggregation
    让模型驾驶，但用专家纠正错误
    """
    new_data = []

    for episode in range(n_episodes):
        # 1. 模型驾驶
        sensors = get_sensors()
        model_action = model.predict(sensors)

        # 2. 专家评估并给出正确动作
        expert_action = expert.get_action(sensors)

        # 3. 将 (传感器, 专家动作) 加入数据集
        new_data.append({
            'sensors': sensors,
            'action': expert_action  # 注意：不是模型的动作！
        })

        # 4. 执行模型的动作（让模型犯错）
        vehicle.apply_control(model_action)

    # 5. 重新训练模型
    dataset.extend(new_data)
    model.train(dataset)
```

```python
class AutonomousAgent:

            'speed': 0.0
        }

    def run(self, vehicle, world):
        """主循环：60Hz 控制频率"""
        clock = pygame.time.Clock()

        while True:
            # 1. 获取最新传感器数据
            sensors = self.get_latest_sensors()

            # 2. 数据预处理
            processed = self.preprocess(sensors)

            # 3. 神经网络推理
            with torch.no_grad():
                prediction = self.model(processed)

            # 4. 后处理输出
            control = self.postprocess(prediction)

            # 5. 应用控制指令
            vehicle.apply_control(control)

            # 6. 维持 60 FPS
            clock.tick(60)

    def preprocess(self, sensors):
        """与训练时一致的预处理"""
        # 图像归一化
        img = sensors['front_camera'].astype(np.float32) / 255.0
        img = (img - MEAN) / STD  # ImageNet 归一化

        # 转为 Tensor
        img_tensor = torch.from_numpy(img).permute(2, 0, 1).unsqueeze(0)

        # LiDAR 点云体素化
        lidar_voxels = self.voxelize(sensors['lidar'])

        return {
            'image': img_tensor.cuda(),
            'lidar': lidar_voxels.cuda(),
            'speed': torch.tensor([sensors['speed']]).cuda()
        }

    def postprocess(self, prediction):
        """将网络输出转为 CARLA 控制指令"""
        steering = float(prediction['steering'].cpu().numpy())
        throttle = float(prediction['throttle'].cpu().numpy())
        brake = float(prediction['brake'].cpu().numpy())

        # 限制范围
        steering = np.clip(steering, -1.0, 1.0)
        throttle = np.clip(throttle, 0.0, 1.0)
        brake = np.clip(brake, 0.0, 1.0)

        return carla.VehicleControl(
            steer=steering,
            throttle=throttle,
            brake=brake,
            hand_brake=False,
            reverse=False
        )
```

### 7.5 统一接口转换

如果您的九头蛇网络输出自定义格式，可以转换为 ROS2 标准：

```python
class ControlConverter:
    """将自定义网络输出转为 ROS2/CARLA 格式"""

    def __init__(self):
        self.max_steer_angle = 70.0  # 车辆最大转向角 (度)
        self.wheelbase = 2.89        # 轴距 (米, 特斯拉 Model 3)

    def hydra_to_carla(self, hydra_output):
        """
        九头蛇网络输出 → CARLA 控制指令

        假设九头蛇输出:
        - path: (N, 2) 预测路径点
        - speed: float 目标速度
        - brake: float 刹车概率
        """
        # 1. 从路径计算转向角（Pure Pursuit 算法）
        lookahead_distance = 5.0  # 前视距离 5 米
        target_point = hydra_output['path'][10]  # 假设第10个点在5米处

        # 计算横向偏差
        lateral_error = target_point[1]  # y 坐标即为横向偏差

        # Pure Pursuit 公式
        steering_angle = np.arctan(2 * self.wheelbase * lateral_error / lookahead_distance**2)
        steering_normalized = steering_angle / np.radians(self.max_steer_angle)

        # 2. 速度误差 → 油门/刹车
        current_speed = get_vehicle_speed()
        speed_error = hydra_output['speed'] - current_speed

        if speed_error > 0:
            throttle = np.clip(speed_error / 10.0, 0, 1)
            brake = 0.0
        else:
            throttle = 0.0
            brake = np.clip(-speed_error / 10.0, 0, 1)

        # 3. 紧急刹车检测
        if hydra_output['brake'] > 0.8:  # 高刹车概率
            throttle = 0.0
            brake = 1.0

        return carla.VehicleControl(
            steer=float(np.clip(steering_normalized, -1, 1)),
            throttle=float(throttle),
            brake=float(brake)
        )
```

## 8. 九头蛇网络架构与输出详解 {#九头蛇网络}

### 8.1 什么是"九头蛇"网络？

**Hydra（九头蛇）** 是一种**多任务学习（Multi-Task Learning, MTL）**架构，其核心思想：

> **一个共享主干网络 + 多个任务专用头部**

```
                    ┌─→ [Head 1] 车道线检测
                    ├─→ [Head 2] 目标检测
[输入图像] → [主干网络] ─┼─→ [Head 3] 深度估计
  (8个相机)   (ResNet-50) ├─→ [Head 4] 语义分割
                    ├─→ [Head 5] 光流估计
                    ├─→ [Head 6] 路径规划
                    ├─→ [Head 7] 速度预测
                    ├─→ [Head 8] 转向角预测
                    └─→ [Head 9] 刹车决策
```

**优势**：
- ✅ 参数共享：减少计算量（8个任务共用1个主干）
- ✅ 特征复用：低级特征（边缘）帮助高级任务（语义理解）
- ✅ 正则化：多任务互相约束，防止过拟合

### 8.2 特斯拉 HydraNet 架构（参考实现）

```python
import torch
import torch.nn as nn
import torchvision.models as models

class HydraNet(nn.Module):
    def __init__(self):
        super().__init__()

        # ===== 主干网络 (Backbone) =====
        # 使用 EfficientNet-B4 作为特征提取器
        backbone = models.efficientnet_b4(pretrained=True)
        self.backbone = nn.Sequential(*list(backbone.children())[:-2])  # 去掉分类头
        # 输出: (B, 1792, H/32, W/32)

        # ===== 特征金字塔网络 (FPN) =====
        self.fpn = FeaturePyramidNetwork(
            in_channels_list=[112, 160, 272, 448, 1792],  # EfficientNet 各层通道数
            out_channels=256
        )

        # ===== 九个任务头部 =====

        # 1. 车道线检测 (语义分割)
        self.lane_head = nn.Sequential(
            nn.Conv2d(256, 128, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(128, 4, 1)  # 输出: 4类 (背景, 左车道线, 右车道线, 中心线)
        )

        # 2. 目标检测 (YOLO 风格)
        self.object_head = YOLOHead(
            num_classes=10,  # 车辆, 行人, 自行车, 交通灯, 停止标志...
            num_anchors=3
        )

        # 3. 深度估计 (单目深度)
        self.depth_head = nn.Sequential(
            nn.Conv2d(256, 128, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(128, 1, 1),
            nn.Sigmoid()  # 输出 [0, 1], 乘以最大深度 100m
        )

        # 4. 语义分割 (13类城市场景)
        self.segmentation_head = nn.Sequential(
            nn.Conv2d(256, 128, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(128, 13, 1)  # 道路, 人行道, 建筑, 植被...
        )

        # 5. 光流估计 (运动预测)
        self.flow_head = FlowNetHead(in_channels=256)

        # 6. 路径规划 (未来轨迹)
        self.path_head = nn.Sequential(
            nn.AdaptiveAvgPool2d(1),  # 全局平均池化
            nn.Flatten(),
            nn.Linear(256, 512),
            nn.ReLU(),
            nn.Linear(512, 20)  # 10个路径点 × 2 (x, y)
        )

        # 7. 速度预测
        self.speed_head = nn.Sequential(
            nn.AdaptiveAvgPool2d(1),
            nn.Flatten(),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, 1)  # 输出: 目标速度 (m/s)
        )

        # 8. 转向角预测
        self.steering_head = nn.Sequential(
            nn.AdaptiveAvgPool2d(1),
            nn.Flatten(),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, 1),
            nn.Tanh()  # 输出: [-1, 1]
        )

        # 9. 刹车决策 (二分类)
        self.brake_head = nn.Sequential(
            nn.AdaptiveAvgPool2d(1),
            nn.Flatten(),
            nn.Linear(256, 64),
            nn.ReLU(),
            nn.Linear(64, 1),
            nn.Sigmoid()  # 输出: 刹车概率 [0, 1]
        )

    def forward(self, images):
        """
        images: (B, 8, 3, H, W) - 8个相机的图像
        """
        B = images.shape[0]

        # 1. 展平批次和相机维度
        images = images.view(B * 8, 3, H, W)

        # 2. 主干网络特征提取
        features = self.backbone(images)  # (B*8, 1792, H', W')

        # 3. FPN 多尺度特征
        fpn_features = self.fpn(features)  # (B*8, 256, H', W')

        # 4. 恢复批次维度
        fpn_features = fpn_features.view(B, 8, 256, H', W')

        # 5. 融合多相机特征 (BEV - Bird's Eye View)
        bev_features = self.camera_to_bev(fpn_features)  # (B, 256, H_bev, W_bev)

        # 6. 九个头部并行预测
        outputs = {
            'lanes': self.lane_head(bev_features),           # (B, 4, H, W)
            'objects': self.object_head(bev_features),       # (B, N, 6) [x, y, w, h, conf, class]
            'depth': self.depth_head(bev_features) * 100,    # (B, 1, H, W) 米
            'segmentation': self.segmentation_head(bev_features),  # (B, 13, H, W)
            'flow': self.flow_head(bev_features),            # (B, 2, H, W)
            'path': self.path_head(bev_features).view(B, 10, 2),  # (B, 10, 2)
            'speed': self.speed_head(bev_features),          # (B, 1)
            'steering': self.steering_head(bev_features),    # (B, 1)
            'brake': self.brake_head(bev_features),          # (B, 1)
        }

        return outputs

    def camera_to_bev(self, camera_features):
        """
        将8个相机的透视图特征投影到鸟瞰图 (BEV)
        这是特斯拉的核心技术之一
        """
        # 简化版本: 使用 Transformer 进行空间变换
        bev_queries = self.bev_queries.weight.unsqueeze(0).repeat(B, 1, 1)
        # bev_queries: (B, 200*200, 256) - 200×200 的 BEV 网格

        # Cross-Attention: BEV 查询相机特征
        bev_features = self.bev_transformer(
            query=bev_queries,
            key=camera_features.flatten(1, 2),  # (B, 8*H'*W', 256)
            value=camera_features.flatten(1, 2)
        )

        # 重塑为空间特征图
        bev_features = bev_features.view(B, 256, 200, 200)
        return bev_features
```

### 8.3 九头蛇网络的输出详解

| 头部 (Head) | 输出形状 | 数值范围 | 物理意义 | 损失函数 |
|-------------|---------|---------|---------|---------|
| **1. 车道线** | (B, 4, H, W) | Logits | 每像素属于4类车道线的概率 | CrossEntropyLoss |
| **2. 目标检测** | (B, N, 6) | [0, W], [0, H], [0, 1] | 边界框 (x, y, w, h, 置信度, 类别) | YOLOLoss |
| **3. 深度** | (B, 1, H, W) | [0, 100] 米 | 每像素的距离 | BerHuLoss |
| **4. 语义分割** | (B, 13, H, W) | Logits | 13类场景元素 (道路/建筑/天空...) | CrossEntropyLoss |
| **5. 光流** | (B, 2, H, W) | [-50, 50] px/frame | 像素运动向量 (用于预测障碍物轨迹) | EPELoss |
| **6. 路径规划** | (B, 10, 2) | 相对坐标 (米) | 未来1秒内10个路径点 (车体坐标系) | L1Loss |
| **7. 速度** | (B, 1) | [0, 30] m/s | 目标速度 | MSELoss |
| **8. 转向角** | (B, 1) | [-1, 1] | 归一化方向盘转角 | MSELoss |
| **9. 刹车** | (B, 1) | [0, 1] | 刹车概率 | BCELoss |

### 8.4 从网络输出到车辆控制

```python
def hydra_output_to_control(outputs, current_state):
    """
    将九头蛇网络的9个输出转为最终控制指令
    """
    # 1. 路径跟踪 → 转向角
    predicted_path = outputs['path'][0]  # (10, 2) - 未来10个点
    steering_from_path = pure_pursuit(predicted_path, lookahead=5.0)

    # 2. 网络直接预测的转向角
    steering_from_network = outputs['steering'][0].item()

    # 3. 加权融合 (网络预测权重更高)
    steering = 0.7 * steering_from_network + 0.3 * steering_from_path

    # 4. 速度控制
    target_speed = outputs['speed'][0].item()
    current_speed = current_state['speed']
    speed_error = target_speed - current_speed

    # PID 控制器
    throttle, brake = pid_controller.update(speed_error)

    # 5. 紧急刹车覆盖
    brake_probability = outputs['brake'][0].item()
    if brake_probability > 0.9:  # 高置信度刹车
        throttle = 0.0
        brake = 1.0

    # 6. 目标检测安全检查
    objects = outputs['objects']  # (N, 6)
    critical_objects = objects[objects[:, 4] > 0.5]  # 置信度 > 0.5

    for obj in critical_objects:
        x, y, w, h, conf, cls = obj
        distance = estimate_distance(x, y, outputs['depth'])

        if distance < 5.0 and cls in [0, 1]:  # 5米内有车或人
            brake = max(brake, 0.8)  # 至少80%刹车

    return {
        'steering': np.clip(steering, -1, 1),
        'throttle': np.clip(throttle, 0, 1),
        'brake': np.clip(brake, 0, 1)
    }
```

#### **步骤1：数据采集 (collect_data.py)**

```python
#!/usr/bin/env python3
import carla
import numpy as np
import h5py
from pathlib import Path

class DataCollector:
    def __init__(self, host='localhost', port=2000):
        self.client = carla.Client(host, port)
        self.client.set_timeout(10.0)
        self.world = self.client.get_world()

        # 数据存储
        self.dataset = []

    def setup_vehicle(self):
        """生成车辆并设置自动驾驶"""
        bp = self.world.get_blueprint_library().find('vehicle.tesla.model3')
        spawn_point = np.random.choice(self.world.get_map().get_spawn_points())
        self.vehicle = self.world.spawn_actor(bp, spawn_point)
        self.vehicle.set_autopilot(True)  # 专家驾驶

    def setup_sensors(self):
        """生成8个相机 + LiDAR"""
        self.sensors = {}
        self.sensor_data = {}

        # 前置相机
        cam_bp = self.world.get_blueprint_library().find('sensor.camera.rgb')
        cam_bp.set_attribute('image_size_x', '1920')
        cam_bp.set_attribute('image_size_y', '1080')
        cam_bp.set_attribute('fov', '70')

        cam_transform = carla.Transform(carla.Location(x=2.5, z=1.4))
        camera = self.world.spawn_actor(cam_bp, cam_transform, attach_to=self.vehicle)
        camera.listen(lambda img: self.sensor_data.update({'front_camera': img}))
        self.sensors['front_camera'] = camera

        # ... 其他7个相机类似 ...

        # LiDAR
        lidar_bp = self.world.get_blueprint_library().find('sensor.lidar.ray_cast')
        lidar_bp.set_attribute('channels', '64')
        lidar_bp.set_attribute('range', '100')

        lidar = self.world.spawn_actor(
            lidar_bp,
            carla.Transform(carla.Location(z=2.4)),
            attach_to=self.vehicle
        )
        lidar.listen(lambda data: self.sensor_data.update({'lidar': data}))
        self.sensors['lidar'] = lidar

    def collect(self, duration=3600):
        """采集1小时数据"""
        import time
        start_time = time.time()

        while time.time() - start_time < duration:
            # 等待所有传感器数据就绪
            if len(self.sensor_data) < 9:  # 8相机 + 1LiDAR
                time.sleep(0.01)
                continue

            # 获取专家控制指令
            control = self.vehicle.get_control()
            velocity = self.vehicle.get_velocity()
            speed = np.linalg.norm([velocity.x, velocity.y, velocity.z]) * 3.6

            # 处理相机数据
            front_img = self.sensor_data['front_camera']
            img_array = np.frombuffer(front_img.raw_data, dtype=np.uint8)
            img_array = img_array.reshape((1080, 1920, 4))[:, :, :3]

            # 处理 LiDAR 数据
            lidar_data = self.sensor_data['lidar']
            points = np.frombuffer(lidar_data.raw_data, dtype=np.float32)
            points = points.reshape((-1, 4))

            # 保存样本
            self.dataset.append({
                'front_camera': img_array,
                'lidar': points,
                'speed': speed,
                'steering': control.steer,
                'throttle': control.throttle,
                'brake': control.brake,
                'timestamp': time.time()
            })

            print(f"采集样本 {len(self.dataset)}, 速度: {speed:.1f} km/h")

            time.sleep(0.05)  # 20 Hz

    def save(self, filename):
        """保存为 HDF5"""
        with h5py.File(filename, 'w') as f:
            n = len(self.dataset)
            f.create_dataset('front_camera', (n, 1080, 1920, 3), dtype='uint8')
            f.create_dataset('steering', (n,), dtype='float32')
            f.create_dataset('throttle', (n,), dtype='float32')
            f.create_dataset('brake', (n,), dtype='float32')
            f.create_dataset('speed', (n,), dtype='float32')

            for i, sample in enumerate(self.dataset):
                f['front_camera'][i] = sample['front_camera']
                f['steering'][i] = sample['steering']
                f['throttle'][i] = sample['throttle']
                f['brake'][i] = sample['brake']
                f['speed'][i] = sample['speed']

        print(f"数据集已保存: {filename} ({n} 样本)")

    def cleanup(self):
        """清理资源"""
        for sensor in self.sensors.values():
            sensor.destroy()
        self.vehicle.destroy()

if __name__ == '__main__':
    collector = DataCollector()
    collector.setup_vehicle()
    collector.setup_sensors()
    collector.collect(duration=3600)  # 1小时
    collector.save('data/training/town01_sunny_001.h5')
    collector.cleanup()
```

#### **步骤2：训练网络 (train.py)**

```python
#!/usr/bin/env python3
import torch
import torch.nn as nn
from torch.utils.data import Dataset, DataLoader
import h5py

class CARLADataset(Dataset):
    def __init__(self, h5_file):
        self.file = h5py.File(h5_file, 'r')
        self.length = len(self.file['front_camera'])

    def __len__(self):
        return self.length

    def __getitem__(self, idx):
        img = self.file['front_camera'][idx]
        img = torch.from_numpy(img).permute(2, 0, 1).float() / 255.0

        return {
            'image': img,
            'steering': self.file['steering'][idx],
            'throttle': self.file['throttle'][idx],
            'brake': self.file['brake'][idx],
        }

# 训练循环
def train():
    dataset = CARLADataset('data/training/town01_sunny_001.h5')
    dataloader = DataLoader(dataset, batch_size=8, shuffle=True, num_workers=4)

    model = HydraNet().cuda()
    optimizer = torch.optim.AdamW(model.parameters(), lr=1e-4)

    for epoch in range(100):
        for batch in dataloader:
            images = batch['image'].cuda()
            outputs = model(images)

            # 多任务损失
            loss = (
                nn.MSELoss()(outputs['steering'], batch['steering'].cuda()) +
                nn.MSELoss()(outputs['throttle'], batch['throttle'].cuda()) +
                nn.BCELoss()(outputs['brake'], batch['brake'].cuda())
            )

            optimizer.zero_grad()
            loss.backward()
            optimizer.step()

        print(f"Epoch {epoch}, Loss: {loss.item():.4f}")
        torch.save(model.state_dict(), f'models/hydranet_epoch{epoch}.pth')

if __name__ == '__main__':
    train()
```

#### **步骤3：部署推理 (agent.py)**

```python
#!/usr/bin/env python3
import carla
import torch
import numpy as np

class AutonomousAgent:
    def __init__(self, model_path):
        self.model = HydraNet()
        self.model.load_state_dict(torch.load(model_path))
        self.model.eval().cuda()

    def run(self, host='localhost', port=2000):
        client = carla.Client(host, port)
        world = client.get_world()

        # 生成车辆
        bp = world.get_blueprint_library().find('vehicle.tesla.model3')
        spawn_point = np.random.choice(world.get_map().get_spawn_points())
        vehicle = world.spawn_actor(bp, spawn_point)

        # 生成相机
        cam_bp = world.get_blueprint_library().find('sensor.camera.rgb')
        cam_bp.set_attribute('image_size_x', '1920')
        cam_bp.set_attribute('image_size_y', '1080')
        camera = world.spawn_actor(
            cam_bp,
            carla.Transform(carla.Location(x=2.5, z=1.4)),
            attach_to=vehicle
        )

        # 相机回调
        def on_camera(image):
            array = np.frombuffer(image.raw_data, dtype=np.uint8)
            array = array.reshape((1080, 1920, 4))[:, :, :3]

            # 推理
            img_tensor = torch.from_numpy(array).permute(2, 0, 1).float() / 255.0
            img_tensor = img_tensor.unsqueeze(0).cuda()

            with torch.no_grad():
                outputs = self.model(img_tensor)

            # 控制
            control = carla.VehicleControl(
                steer=float(outputs['steering'].cpu().numpy()),
                throttle=float(outputs['throttle'].cpu().numpy()),
                brake=float(outputs['brake'].cpu().numpy())
            )
            vehicle.apply_control(control)

        camera.listen(on_camera)

        # 保持运行
        try:
            while True:
                world.tick()
        except KeyboardInterrupt:
            camera.destroy()
            vehicle.destroy()

if __name__ == '__main__':
    agent = AutonomousAgent('models/hydranet_epoch99.pth')
    agent.run()
```

### 10.1 关键要点回顾

1. **CARLA 提供完整的仿真环境**
   - UE5 逼真渲染 + 物理引擎

### 10.3 常见坑点与解决方案

| 问题 | 原因 | 解决方案 |
|-----|------|---------|
| 模型在仿真中抖动 | 网络输出不稳定 | 添加时间平滑滤波器 (EMA) |
| 转弯时冲出车道 | 训练数据直线场景过多 | 增加弯道数据，使用路径规划辅助 |
| 遇到障碍物不刹车 | 缺少紧急刹车样本 | DAgger 算法采集边缘案例 |
| 推理延迟 > 100ms | 网络太大或 GPU 利用率低 | TensorRT 加速，批处理多相机 |
| Sim2Real 差距大 | 仿真图像与真实世界不匹配 | 域自适应（GAN），真实世界微调 |
