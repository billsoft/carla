# 体素生成逻辑重构方案

## 📋 用户需求理解

### 核心需求

**体素网格分为两部分处理**:

1. **地面及地下部分 (Z < 0)**: 索引 0-19 (共 20 层)
   - 只遍历地表一层 (Z=0 层)
   - 查询 UE/CARLA Map API 获取地形材质类型
   - 根据类型分类: 道路 (11)、人行道 (13)、隔离带/护栏 (1)、交通标线 (8)、通用地面 (12)、地形 (14)
   - **向下填充**: Z=0 层的类别直接复制到正下方所有体素 (Z=-1, -2, ..., -19)
   - **逐层遍历 Z=0, -1, -2, ... 确保完整覆盖**

2. **地上部分 (Z >= 0)**: 索引 20-39 (共 20 层)
   - 获取所有 Actors (车辆、行人、建筑物、道具等)
   - 使用深度相机进行可见性过滤
   - 光栅化 Bounding Box 到体素网格
   - **与 GitHub 原始逻辑保持一致**

3. **最终拼接**: 512×512×40 体素网格
   - 下半部分 (0-19): 地面及地下
   - 上半部分 (20-39): 地上物体

### 坐标系要求

- **World-Aligned 坐标系** (对齐世界坐标轴)
- Grid 原点: Ego 位置
- Grid X = World X - Ego X (East 方向)
- Grid Y = World Y - Ego Y (North 方向)
- Grid Z = World Z - Ego Z (Up 方向)
- **纯平移矩阵，无旋转**

**地面填充**:

**结果**: 两者使用不同的 Z 基准，导致高度对不齐

### 问题 3: 没有严格区分地面/地上

**期望**:
- 地面: Z < 0 (Ego 车轮以下)
- 地上: Z >= 0 (Ego 车轮以上)

## 🎯 重构方案设计

### 总体架构

```
generate()
    ├─ 1. 初始化体素网格 (512×512×40, 全部为 0)
    ├─ 2. 填充地面及地下 (Z < 0)
    │     └─ _fill_ground_and_underground()
    │           ├─ 遍历 Z=0 层的 XY 平面
    │           ├─ 查询 Map 获取地形类型
    │           ├─ 填充 Z=0 层
    │           └─ 向下复制到 Z=-1, -2, ..., -19
    ├─ 3. 填充地上物体 (Z >= 0)
    │     └─ _fill_above_ground()
    │           ├─ 获取所有 Actors
    │           ├─ 深度相机可见性过滤
    │           └─ 光栅化 Bounding Box
    └─ 4. 返回 occupancy, actor_ids
```

### 详细设计

#### 1. 坐标系统一

**Grid 坐标系定义** (World-Aligned):
```python
# Grid 原点: Ego 位置
# Grid 范围:
#   X: [-51.2, 51.2] -> 索引 [0, 511]
#   Y: [-51.2, 51.2] -> 索引 [0, 511]
#   Z: [-4.0, 4.0] -> 索引 [0, 39]

# 世界坐标 -> Grid 坐标
gx = wx - ego_location.x
gy = wy - ego_location.y
gz = wz - ego_location.z

# Grid 坐标 -> 数组索引
ix = int((gx - x_range[0]) / resolution)
iy = int((gy - y_range[0]) / resolution)
iz = int((gz - z_range[0]) / resolution)
```

**Z 轴分界**:
```python
# 假设 Ego 车轮接地，车体中心高度 ego_location.z = 1.0m
# 路面高度约为 ego_location.z - 1.0 = 0.0m (世界坐标)

# Grid Z = 0:
#   世界 Z = ego_location.z + z_range[0] = 1.0 + (-4.0) = -3.0m

# Grid Z = 20 (中间层):
#   世界 Z = ego_location.z + (20 * 0.2 - 4.0) = 1.0 + 0.0 = 1.0m = Ego 车体中心

# 地面层 (路面):
#   世界 Z ≈ 0.0m
#   Grid Z = (0.0 - 1.0 - (-4.0)) / 0.2 = 3.0 / 0.2 = 15

# ⚠️ 修正: 应该让路面层在 Grid Z = 20 附近 (中间层)
# 需要调整 Ego 高度计算或 Z 范围
```

**重新定义 Z 范围**:
```python
# 方案 A: 调整 Z 范围，使路面层在 Z=20 (索引中间)
# 假设路面在 Grid Z = 20
# 世界路面 Z = 0.0m
# Ego 车体中心 Z = 1.0m
# Grid Z = (世界 Z - Ego Z - z_range[0]) / resolution
# 20 = (0.0 - 1.0 - z_range[0]) / 0.2
# 20 * 0.2 = -1.0 - z_range[0]
# z_range[0] = -1.0 - 4.0 = -5.0

# 修正后的 Z 范围: [-5.0, 3.0] (共 8.0m, 40 层)
# 路面层: Grid Z = (0.0 - 1.0 - (-5.0)) / 0.2 = 4.0 / 0.2 = 20 ✅

# 地下: Z < 20 (索引 0-19, 对应世界 -5.0m ~ 1.0m)
# 地上: Z >= 20 (索引 20-39, 对应世界 1.0m ~ 9.0m)
```

**⚠️ 简化方案: 不改变 Z 范围，使用当前 [-4.0, 4.0]**:

# 当前 Z 范围: [-4.0, 4.0]
# Ego 车体中心: ego_location.z

# 路面层世界高度: 通过 get_waypoint 查询得到 ground_z_world
# 路面层 Grid 高度: gz_ground = ground_z_world - ego_location.z

# 例如:
# ground_z_world = 0.0m
# ego_location.z = 1.0m

# 路面: iz = iz_ground (索引 15)

#### 2. 地面及地下填充逻辑

**函数**: `_fill_ground_and_underground()`

**步骤**:

1. **查询 Ego 所在路面高度**:
```python
start_waypoint = map_instance.get_waypoint(ego_location, project_to_road=True)
ground_z_world = start_waypoint.transform.location.z if start_waypoint else ego_location.z - 1.0
gz_ground = ground_z_world - ego_location.z  # 路面相对于 Ego 的高度
iz_ground = int((gz_ground - self.z_range[0]) / self.resolution)
iz_ground = max(0, min(self.grid_size[2] - 1, iz_ground))
```

2. **世界对齐采样** (与 GitHub 原始逻辑一致):
```python
cache_res = 1.0  # 采样分辨率 1.0m
range_margin = 60.0  # 采样范围 ±60m

# 对齐到整数网格 (世界坐标)
x_world_min = np.floor((ego_location.x - range_margin) / cache_res) * cache_res
x_world_max = np.ceil((ego_location.x + range_margin) / cache_res) * cache_res
y_world_min = np.floor((ego_location.y - range_margin) / cache_res) * cache_res
y_world_max = np.ceil((ego_location.y + range_margin) / cache_res) * cache_res

x_world_samples = np.arange(x_world_min, x_world_max, cache_res)
y_world_samples = np.arange(y_world_min, y_world_max, cache_res)
```

3. **遍历采样点，查询 Map**:
```python
for wx in x_world_samples:
    for wy in y_world_samples:
        # 缓存检查
        cache_key = (int(round(wx/cache_res)), int(round(wy/cache_res)))

        if cache_key in self.ground_cache:
            label, wz = self.ground_cache[cache_key]['label'], self.ground_cache[cache_key]['z']
        else:
            # 查询 Map
            loc = carla.Location(x=wx, y=wy, z=ground_z_world)
            label = 14  # 默认 terrain
            wz = ground_z_world

            # 查询道路
            wp = map_instance.get_waypoint(loc, project_to_road=True, lane_type=carla.LaneType.Driving)
            if wp and loc.distance(wp.transform.location) < (wp.lane_width / 2.0 + 0.5):
                label = 11  # driveable_surface
                wz = wp.transform.location.z
            else:
                # 查询人行道
                wp_sw = map_instance.get_waypoint(loc, project_to_road=True, lane_type=carla.LaneType.Sidewalk)
                if wp_sw and loc.distance(wp_sw.transform.location) < (wp_sw.lane_width / 2.0 + 0.5):
                    label = 13  # sidewalk
                    wz = wp_sw.transform.location.z

            # 更新缓存
            self.ground_cache[cache_key] = {'label': label, 'z': wz}
```

4. **转换到 Grid 索引 (World-Aligned)**:
```python
        # 世界坐标 -> Grid 坐标 (纯平移)
        gx = wx - ego_location.x
        gy = wy - ego_location.y
        gz = wz - ego_location.z

        # Grid 坐标 -> 数组索引
        ix = int((gx - self.x_range[0]) / self.resolution)
        iy = int((gy - self.y_range[0]) / self.resolution)
        iz = int((gz - self.z_range[0]) / self.resolution)

        # 边界检查
        if not (0 <= ix < self.grid_size[0] and 0 <= iy < self.grid_size[1]):
            continue
```

5. **填充地表层 (iz 层) 及向下复制**:
```python
        # 填充半径 (1.0m 采样点 -> 约 5×5 体素)
        radius = int(cache_res / self.resolution / 2.0) + 1

        ix_min = max(0, ix - radius)
        ix_max = min(self.grid_size[0], ix + radius + 1)
        iy_min = max(0, iy - radius)
        iy_max = min(self.grid_size[1], iy + radius + 1)

        # 地表层索引 (iz 可能略有起伏)
        iz_surface = max(0, min(self.grid_size[2] - 1, iz))

        # 填充地表层
        if iz_surface < self.grid_size[2]:
            occupancy[ix_min:ix_max, iy_min:iy_max, iz_surface] = label
            actor_ids[ix_min:ix_max, iy_min:iy_max, iz_surface] = -(1000 + label)

        # 向下复制到所有地下层 (从 iz_surface-1 到 0)
        for iz_underground in range(iz_surface - 1, -1, -1):
            occupancy[ix_min:ix_max, iy_min:iy_max, iz_underground] = label
            actor_ids[ix_min:ix_max, iy_min:iy_max, iz_underground] = -(1000 + label)
```

**特殊处理**:
- **隔离带/护栏 (barrier, 1)**: 通过 CityObjectLabel.Fences 查询
- **交通标线 (traffic_cone, 8)**: 通过 CityObjectLabel.RoadLines 或 TrafficSigns 查询
- **需要遍历 Environment Objects**

#### 3. 地上物体填充逻辑

**函数**: `_fill_above_ground()`

**步骤** (与 GitHub 原始逻辑一致):

1. **获取所有 Actors**:
```python
actors = world.get_actors()
vehicles = actors.filter('vehicle.*')
walkers = actors.filter('walker.pedestrian.*')
props = actors.filter('static.prop.*')
traffic = actors.filter('traffic.*')

all_actors = list(vehicles) + list(walkers) + list(props) + list(traffic)
```

2. **获取环境物体** (建筑物等):
```python
env_objs = world.get_environment_objects(carla.CityObjectLabel.Any)
```

3. **光栅化 Bounding Box**:
```python
for actor in all_actors:
    # 距离过滤
    if actor.get_location().distance(ego_location) > 60.0:
        continue

    # 获取类别标签
    occ_label = get_occupancy_label_from_actor(actor)

    # 光栅化 (与 GitHub 原始逻辑一致)

        occupancy, actor_ids,
        actor.bounding_box, actor.get_transform(),
        grid_to_world_matrix, occ_label, actor.id
    )
```

4. **深度相机可见性过滤** (在主函数中):
```python
# 地上部分过滤
if visibility_data is not None:
    filtered_occ, filtered_ids = visibility_filter.run(
        occupancy, actor_ids, grid_config, depth_data, ego_matrix
    )

    # 保留地下部分，只过滤地上部分
    # 假设 iz_ground = 15
    occupancy[:, :, iz_ground+1:] = filtered_occ[:, :, iz_ground+1:]
    actor_ids[:, :, iz_ground+1:] = filtered_ids[:, :, iz_ground+1:]
```

#### 4. Z 范围分配

**当前 z_range = [-4.0, 4.0]**:

假设:
- Ego 车体中心高度: `ego_location.z = 1.0m` (世界坐标)
- 路面高度: `ground_z_world = 0.0m` (世界坐标)
- 路面相对高度: `gz_ground = 0.0 - 1.0 = -1.0m` (Grid 坐标)

Grid Z 索引分配:
```python
# iz = int((gz - z_range[0]) / resolution)
# iz = int((gz - (-4.0)) / 0.2)

# 地下部分 (gz < -1.0):
iz = 0:  gz = -4.0m (Ego 下方 3.0m, 路面下方 4.0m)
iz = 5:  gz = -3.0m
iz = 10: gz = -2.0m
iz = 14: gz = -1.2m

# 路面层 (gz ≈ -1.0):
iz = 15: gz = -1.0m ✅ 路面层

# 地上部分 (gz > -1.0):
iz = 20: gz = 0.0m (Ego 车体中心)
iz = 30: gz = 2.0m
iz = 39: gz = 3.8m (Ego 上方 2.8m)
```

**分界方案**:
- **地下及地面**: iz ∈ [0, iz_ground] (动态计算)
- **地上**: iz ∈ (iz_ground, 39]
