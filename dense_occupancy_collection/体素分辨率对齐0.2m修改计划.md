# 体素分辨率对齐 0.2m × 0.2m × 0.2m 修改计划

## 📌 一、需求整理

### 用户目标
1. **对齐 OpenOccupancy-nuScenes 标准**:
   - 体素分辨率: **0.2m × 0.2m × 0.2m** (每个体素边长 0.2米)
   - 体素网格: **512×512×40** (nuScenes 标准)
   - 覆盖范围: **[-51.2m, 51.2m] × [-51.2m, 51.2m] × [-4.0m, 4.0m]**

2. **自动驾驶可用性要求**:
   - 0.2米分辨率是自动驾驶的**最低可用标准**
   - 0.4米或0.5米分辨率**不符合安全要求**,无法检测小于0.5米的障碍物
   - 小于0.5米的障碍物(如路障、小型交通标识)可能造成交通事故

3. **坐标严格对齐**:
   - 每个体素的物理坐标必须严格对应 UE5.5 世界坐标
   - 体素索引 `[i, j, k]` 必须精确映射到 UE5 中的 3D 位置 `(x, y, z)`
   - 遍历体素网格时,读取的 Actor 位置必须与体素中心完全对应

### 当前问题诊断

#### ❌ 问题 1: 网格尺寸不符合 nuScenes 标准
- **期望**: 512×512×40 (nuScenes)
- **实际**: 500×500×40 (当前)
- **差异**: 少了 12×12×0 = 144 个体素/行列
- **影响**: 覆盖范围少了 2.4米 (12 × 0.2m)

#### ❌ 问题 2: ground_truth_voxel_generator.py 使用错误的 resolution 默认值
```python
# ground_truth_voxel_generator.py:32
def __init__(self,
             x_range=(-50.0, 50.0),
             y_range=(-50.0, 50.0),
             z_range=(-4.0, 4.0),
             resolution=0.5):  # ❌ 错误! 应该是 0.2
```
- **问题**: 如果调用时没有显式传入 `resolution=0.2`,会使用 0.5m 的错误分辨率
- **后果**: 体素网格变为 200×200×16,精度严重下降

#### ❌ 问题 3: 体素中心坐标计算可能存在浮点误差
```python
# ground_truth_voxel_generator.py:387-392
lx = np.linspace(self.x_range[0] + (min_ix + 0.5)*self.resolution,
                 self.x_range[0] + (max_ix - 0.5)*self.resolution, max_ix - min_ix)
```
- **问题**: `linspace` 用于计算体素中心,但浮点累积误差可能导致坐标偏移
- **风险**: 对于 512×512 的大网格,累积误差可能达到 1-2mm

#### ⚠️ 问题 4: 覆盖范围与 nuScenes 不完全一致
- **nuScenes**: 通常是 [-51.2m, 51.2m] (512 × 0.2m)
- **当前**: [-50.0m, 50.0m] (500 × 0.2m)
- **影响**: 边缘 1.2米的区域无法覆盖

### 3.1 目标参数

#### 方案 A: 严格对齐 nuScenes 标准 (推荐)

#### 修改 3: `ground_truth_voxel_generator.py` - 优化体素中心坐标计算

**文件**: `dense_occupancy_collection/processing/ground_truth_voxel_generator.py`

**修改位置**: Lines 387-392

**问题分析**:
当前使用 `linspace` 计算体素中心,可能存在浮点累积误差:
```python
# 当前实现 (可能有误差)
lx = np.linspace(self.x_range[0] + (min_ix + 0.5)*self.resolution,
                 self.x_range[0] + (max_ix - 0.5)*self.resolution, max_ix - min_ix)
```

**修改为更精确的索引计算**:
```python
# 方法 1: 使用 arange + 索引计算 (推荐,精度最高)
lx = self.x_range[0] + (np.arange(min_ix, max_ix) + 0.5) * self.resolution
ly = self.y_range[0] + (np.arange(min_iy, max_iy) + 0.5) * self.resolution
lz = self.z_range[0] + (np.arange(min_iz, max_iz) + 0.5) * self.resolution

sub_xv, sub_yv, sub_zv = np.meshgrid(lx, ly, lz, indexing='ij')
sub_points_ego = np.stack([sub_xv, sub_yv, sub_zv, np.ones_like(sub_xv)], axis=-1).reshape(-1, 4)
```

**为什么这样更精确？**
- `arange` 使用整数索引,避免浮点累积
- 体素中心 = `x_min + (index + 0.5) * resolution`
- 保证每个体素中心精确对应物理坐标

**同样修改位置 2**: Lines 182-183 (地面填充部分)
```python
# 修改前
x_coords = self.x_range[0] + (x_indices + 0.5) * self.resolution
y_coords = self.y_range[0] + (y_indices + 0.5) * self.resolution

# 修改后 (已经正确,无需改动)
# 但需确认 x_indices, y_indices 是 np.arange 生成的整数数组
```

#### 修改 4: `ground_truth_voxel_generator.py` - 索引边界计算优化

**文件**: `dense_occupancy_collection/processing/ground_truth_voxel_generator.py`

**修改位置**: Lines 359-364, 598-607

**当前实现**:
```python
min_ix = int(np.floor((np.min(xs_ego) - self.x_range[0]) / self.resolution))
max_ix = int(np.ceil((np.max(xs_ego) - self.x_range[0]) / self.resolution))
```

**问题**: `np.floor` 和 `np.ceil` 可能因浮点精度问题产生 off-by-one 错误

**优化方案**:
```python
# ⭐ 使用更健壮的索引计算
def _world_to_grid_index(self, coord, range_min, range_max, grid_size):
    """
    将世界坐标转换为网格索引

    Args:
        coord: 世界坐标值 (单个或数组)
        range_min: 网格最小值 (e.g., -51.2)
        range_max: 网格最大值 (e.g., 51.2)
        grid_size: 网格大小 (e.g., 512)

    Returns:
        index: 网格索引 (0 到 grid_size-1)
    """
    # 归一化到 [0, 1]
    normalized = (coord - range_min) / (range_max - range_min)
    # 转换为索引 [0, grid_size]
    index = normalized * grid_size
    return index

# 使用示例
min_ix = int(np.floor(self._world_to_grid_index(np.min(xs_ego), self.x_range[0], self.x_range[1], self.grid_size[0])))
max_ix = int(np.ceil(self._world_to_grid_index(np.max(xs_ego), self.x_range[0], self.x_range[1], self.grid_size[0])))

# Clip to valid range
min_ix = max(0, min_ix)
max_ix = min(self.grid_size[0], max_ix)
```

**或者更简洁的版本** (保持当前逻辑但添加边界保护):
```python
# 保持当前实现,但添加 epsilon 容差
epsilon = self.resolution * 0.01  # 0.002m 容差

min_ix = int(np.floor((np.min(xs_ego) - self.x_range[0] - epsilon) / self.resolution))
max_ix = int(np.ceil((np.max(xs_ego) - self.x_range[0] + epsilon) / self.resolution))
min_iy = int(np.floor((np.min(ys_ego) - self.y_range[0] - epsilon) / self.resolution))
```

#### 修改 5: 添加坐标验证脚本

**新增文件**: `dense_occupancy_collection/scripts/verify_voxel_alignment.py`

**目的**: 验证体素坐标与 UE5 世界坐标的严格对应

```python
"""
体素坐标对齐验证脚本
验证体素索引与 UE5 世界坐标的精确映射关系
"""

import numpy as np
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).parent.parent.parent))

from dense_occupancy_collection.config.occupancy_config import (
    X_RANGE, Y_RANGE, Z_RANGE, RESOLUTION, GRID_SIZE
)

def voxel_index_to_world_coord(ix, iy, iz):
    """
    体素索引 -> 世界坐标 (体素中心)

    Args:
        ix, iy, iz: 体素索引 [0, GRID_SIZE-1]

    Returns:
        x, y, z: 世界坐标 (米)
    """
    x = X_RANGE[0] + (ix + 0.5) * RESOLUTION
    y = Y_RANGE[0] + (iy + 0.5) * RESOLUTION
    z = Z_RANGE[0] + (iz + 0.5) * RESOLUTION
    return x, y, z

def world_coord_to_voxel_index(x, y, z):
    """
    世界坐标 -> 体素索引

    Args:
        x, y, z: 世界坐标 (米)

    Returns:
        ix, iy, iz: 体素索引
    """
    ix = int(np.floor((x - X_RANGE[0]) / RESOLUTION))
    iy = int(np.floor((y - Y_RANGE[0]) / RESOLUTION))
    iz = int(np.floor((z - Z_RANGE[0]) / RESOLUTION))

    # Clip to valid range
    ix = np.clip(ix, 0, GRID_SIZE[0] - 1)
    iy = np.clip(iy, 0, GRID_SIZE[1] - 1)
    iz = np.clip(iz, 0, GRID_SIZE[2] - 1)

    return ix, iy, iz

def test_round_trip():
    """测试往返转换精度"""
    print("=" * 60)
    print("体素坐标往返转换测试")
    print("=" * 60)

    test_cases = [
        (0, 0, 0),           # 网格起点
        (255, 255, 19),      # 网格中心
        (511, 511, 39),      # 网格终点
        (100, 200, 15),      # 随机点
    ]

    max_error = 0.0

    for ix, iy, iz in test_cases:
        # 索引 -> 坐标
        x, y, z = voxel_index_to_world_coord(ix, iy, iz)

        # 坐标 -> 索引
        ix2, iy2, iz2 = world_coord_to_voxel_index(x, y, z)

        # 验证
        error = abs(ix - ix2) + abs(iy - iy2) + abs(iz - iz2)
        max_error = max(max_error, error)

        status = "✅" if error == 0 else "❌"
        print(f"{status} [{ix:3d}, {iy:3d}, {iz:2d}] -> ({x:6.2f}, {y:6.2f}, {z:5.2f}) -> [{ix2:3d}, {iy2:3d}, {iz2:2d}]")

    print(f"\n最大索引误差: {max_error} (期望: 0)")
    assert max_error == 0, "坐标转换存在误差!"
    print("✅ 所有测试通过\n")

def test_boundary_precision():
    """测试边界体素的坐标精度"""
    print("=" * 60)
    print("边界体素坐标精度测试")
    print("=" * 60)

    # 测试第一个和最后一个体素
    x_first, _, _ = voxel_index_to_world_coord(0, 0, 0)
    x_last, _, _ = voxel_index_to_world_coord(GRID_SIZE[0] - 1, 0, 0)

    # 第一个体素中心应该在 x_min + 0.5 * resolution
    expected_first = X_RANGE[0] + 0.5 * RESOLUTION
    # 最后一个体素中心应该在 x_max - 0.5 * resolution
    expected_last = X_RANGE[1] - 0.5 * RESOLUTION

    error_first = abs(x_first - expected_first)
    error_last = abs(x_last - expected_last)

    print(f"第一个体素 (ix=0):")
    print(f"  实际 X 坐标: {x_first:.6f} m")
    print(f"  期望 X 坐标: {expected_first:.6f} m")
    print(f"  误差: {error_first:.9f} m")

    print(f"\n最后一个体素 (ix={GRID_SIZE[0]-1}):")
    print(f"  实际 X 坐标: {x_last:.6f} m")
    print(f"  期望 X 坐标: {expected_last:.6f} m")
    print(f"  误差: {error_last:.9f} m")

    # 容许 1e-6 米误差 (1 微米)
    assert error_first < 1e-6, f"第一个体素坐标误差过大: {error_first}"
    assert error_last < 1e-6, f"最后一个体素坐标误差过大: {error_last}"
    print("\n✅ 边界精度测试通过\n")

def test_grid_coverage():
    """测试网格覆盖范围"""
    print("=" * 60)
    print("网格覆盖范围验证")
    print("=" * 60)

    print(f"X 范围: {X_RANGE} m")
    print(f"Y 范围: {Y_RANGE} m")
    print(f"Z 范围: {Z_RANGE} m")
    print(f"分辨率: {RESOLUTION} m")
    print(f"网格尺寸: {GRID_SIZE}")

    # 验证覆盖范围
    x_span = X_RANGE[1] - X_RANGE[0]
    y_span = Y_RANGE[1] - Y_RANGE[0]
    z_span = Z_RANGE[1] - Z_RANGE[0]

    expected_x = GRID_SIZE[0] * RESOLUTION
    expected_y = GRID_SIZE[1] * RESOLUTION
    expected_z = GRID_SIZE[2] * RESOLUTION

    print(f"\n实际覆盖:")
    print(f"  X: {x_span:.2f} m (期望: {expected_x:.2f} m)")
    print(f"  Y: {y_span:.2f} m (期望: {expected_y:.2f} m)")
    print(f"  Z: {z_span:.2f} m (期望: {expected_z:.2f} m)")

    # 验证
    assert abs(x_span - expected_x) < 1e-6, f"X 覆盖范围错误"
    assert abs(y_span - expected_y) < 1e-6, f"Y 覆盖范围错误"
    assert abs(z_span - expected_z) < 1e-6, f"Z 覆盖范围错误"

    print("\n✅ 覆盖范围验证通过\n")

if __name__ == '__main__':
    print("\n" + "🔍 体素坐标对齐验证".center(60) + "\n")

    test_grid_coverage()
    test_boundary_precision()
    test_round_trip()

    print("=" * 60)
    print("✅ 所有验证通过! 体素坐标与 UE5 世界坐标严格对齐".center(60))
    print("=" * 60)
```
