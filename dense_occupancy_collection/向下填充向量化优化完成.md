**解决**: 使用 NumPy 3D 广播操作,一次性填充所有列

## ✅ 优化方案: 3D 广播向量化

### 核心思想

**关键洞察**:
- 我们已经有了每列的地表信息 (第一遍填充的结果)
- 只需要找到每列的地表高度,然后向下填充
- 这是一个**纯几何操作**,可以完全向量化

**算法步骤**:
1. **找地表**: 对每列,找到最高的非零体素 (地表位置)
2. **提取标签**: 获取地表的类别和 Actor ID
3. **生成掩码**: 计算哪些体素需要填充 (Z < surface_z 且为空)
4. **批量填充**: 一次性填充所有满足条件的体素

---

### 优化代码 (Line 387-444)

```python
# ⭐⭐⭐ 性能优化: 向量化向下填充,消除双重循环 ⭐⭐⭐
# 根因: 512×512 的双重 Python 循环极慢 (8-10秒)
# 解决: 使用 NumPy 3D 广播一次性填充所有列 (预计 0.1-0.5秒)

t_start_downfill = time.time()

# 1. 找到每列的地表高度索引 (最高的非零体素)
non_zero_mask = (occupancy != 0)

# 技巧: 反转 Z 轴,使用 argmax 找第一个 True
non_zero_mask_reversed = non_zero_mask[:, :, ::-1]
has_surface = np.any(non_zero_mask_reversed, axis=2)
surface_z_reversed = np.argmax(non_zero_mask_reversed, axis=2)
surface_z = self.grid_size[2] - 1 - surface_z_reversed

# 2. 提取每列的地表标签和 Actor ID
ix_grid, iy_grid = np.meshgrid(np.arange(self.grid_size[0]),
                               np.arange(self.grid_size[1]),
                               indexing='ij')

surface_labels = np.where(has_surface,
                          occupancy[ix_grid, iy_grid, surface_z],
                          0)
surface_aids = np.where(has_surface,
                       actor_ids[ix_grid, iy_grid, surface_z],
                       0)

# 3. 创建 3D Z 坐标网格
Z_grid = np.arange(self.grid_size[2])[None, None, :]  # (1, 1, 40)
surface_z_3d = surface_z[:, :, None]  # (512, 512, 1)

# 4. 生成填充掩码: Z < surface_z 且 occupancy == 0
fill_mask = (Z_grid < surface_z_3d) & (occupancy == 0) & has_surface[:, :, None]

# 5. 向量化填充 (广播操作)
surface_labels_3d = surface_labels[:, :, None]
surface_aids_3d = surface_aids[:, :, None]

occupancy[fill_mask] = np.broadcast_to(surface_labels_3d, occupancy.shape)[fill_mask]
actor_ids[fill_mask] = np.broadcast_to(surface_aids_3d, actor_ids.shape)[fill_mask]

total_filled = np.count_nonzero(fill_mask)
filled_columns = np.count_nonzero(has_surface)

t_downfill_elapsed = time.time() - t_start_downfill
print(f"[地面填充] 完成 {filled_columns} 列填充, 总填充 {total_filled} 个体素 (耗时: {t_downfill_elapsed:.3f}s)")
```

---

### 技术细节

#### 1. 反转 Z 轴技巧

**问题**: `np.argmax` 返回第一个 True 的索引,但我们需要从上到下搜索

**解决**:
```python
# 原始 Z 轴: [0, 1, 2, ..., 39] (下→上)
# 反转后:    [39, 38, 37, ..., 0] (上→下)
non_zero_mask_reversed = non_zero_mask[:, :, ::-1]
surface_z_reversed = np.argmax(non_zero_mask_reversed, axis=2)

# 转换回原始索引
surface_z = self.grid_size[2] - 1 - surface_z_reversed
```

#### 2. 3D 广播

**核心操作**:
```python
# surface_labels: (512, 512) → (512, 512, 1) → 广播到 (512, 512, 40)
# Z_grid:         (1, 1, 40) → 广播到 (512, 512, 40)
# fill_mask:      (512, 512, 40) 布尔数组

# 一次性填充所有满足条件的体素
occupancy[fill_mask] = np.broadcast_to(surface_labels_3d, occupancy.shape)[fill_mask]
```

**优势**:
- 利用 NumPy 的 C 语言实现
- 可以使用 SIMD 指令
- 缓存友好
- 避免 Python 循环开销

#### 3. 逻辑等价性

**原逻辑**:
```python
for each column (ix, iy):
    find surface_z  # 地表高度
    for iz in range(surface_z - 1, -1, -1):
        if occupancy[ix, iy, iz] == 0:
            occupancy[ix, iy, iz] = surface_label
```

**向量化逻辑**:
```python
# 1. 找到所有列的 surface_z
# 2. 生成掩码: (Z < surface_z) & (occupancy == 0)
# 3. 批量赋值
occupancy[fill_mask] = surface_labels[广播]
```

**证明**: ✅ 完全等价

**临时数组**:

**总内存开销**: 约 **20 MB** (可接受)

### 2. 边界情况

**没有地表的列**:
```python
has_surface = np.any(non_zero_mask_reversed, axis=2)
surface_labels = np.where(has_surface, ..., 0)
```
- 使用 `has_surface` 掩码避免处理无效列
- 没有地表的列设为 0,不影响结果

### 3. Z 轴索引

**重要**: 确保 Z 轴方向一致
- `occupancy[:, :, 0]` 是最底层
- `occupancy[:, :, 39]` 是最顶层
- 向下填充: 从 `surface_z - 1` 到 `0`
