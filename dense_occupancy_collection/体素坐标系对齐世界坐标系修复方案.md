# 体素坐标系对齐世界坐标系修复方案

## 问题诊断

### 核心问题 ⭐⭐⭐⭐⭐ **根本原因**

**当前错误实现**:
```
体素网格坐标系 = Ego车辆局部坐标系
                ↓
体素坐标系随车辆的偏航(yaw)、俯仰(pitch)、滚转(roll)旋转
                ↓
当车辆转弯时,整个体素网格也跟着旋转
                ↓
同一个静态物体(如建筑物)在不同帧被映射到不同的体素位置
                ↓
导致物体在体素网格中"闪烁"!
```

### 问题示例

假设一个静态建筑物在**世界坐标系**中位于 `(10m, 20m, 0m)`:

**帧 N** (车辆朝向北, yaw=0°):
- Ego位置: `(0, 0, 0)`
- Ego朝向: 北 (0°)
- 体素坐标系: X=东, Y=北, Z=上
- 建筑物在体素中: `voxel[10m东, 20m北, 0m] = Building` ✅

**帧 N+1** (车辆转弯, yaw=90°):
- Ego位置: `(5, 5, 0)`
- Ego朝向: 东 (90°) ⚠️ **旋转了!**
- **错误**: 体素坐标系跟着旋转 → X=北, Y=西, Z=上
- 建筑物相对于旋转后的Ego坐标系: `(-15m西, 5m北, 0m)`
- 建筑物在体素中: `voxel[-15m, 5m, 0m]` ❌ **位置变了!**

**结果**: 建筑物从 `voxel[50, 100, 20]` 跳到 `voxel[-75, 25, 20]` → **闪烁!**

---

## 正确实现

### 目标 ⭐

**体素网格必须对齐世界坐标系**:
```
体素坐标系 = 世界坐标系 (固定东南西北)
           ↓
只有体素网格的中心跟随车辆位置移动
           ↓
体素网格的X轴永远指向世界东方
体素网格的Y轴永远指向世界北方
体素网格的Z轴永远垂直向上
           ↓
静态物体始终映射到相同的体素位置
           ↓
不会闪烁! ✅
```

### 示例 (正确实现)

**帧 N** (车辆朝向北, yaw=0°):
- Ego位置: `(0, 0, 0)` (世界坐标系)
- 体素网格中心: Ego位置
- 体素坐标系: **固定对齐世界** → X=东, Y=北, Z=上
- 建筑物世界坐标: `(10, 20, 0)`
- 建筑物在体素中: `voxel[10m, 20m, 0m]` ✅

**帧 N+1** (车辆转弯, yaw=90°):
- Ego位置: `(5, 5, 0)` (世界坐标系)
- 体素网格中心: Ego新位置 ⭐ **只有中心移动**
- 体素坐标系: **仍然对齐世界** → X=东, Y=北, Z=上 ⭐ **不旋转!**
- 建筑物世界坐标: `(10, 20, 0)` (静态不变)
- 建筑物相对于新体素中心: `(10-5, 20-5, 0) = (5, 15, 0)`
- 建筑物在体素中: `voxel[5m, 15m, 0m]` ✅ **位置连续变化**

**结果**: 建筑物从 `voxel[50, 100, 20]` 平滑移动到 `voxel[25, 75, 20]` → **不闪烁!** ✅

### 修复方案 ⭐⭐⭐⭐⭐

#### 核心思路

**将体素网格从 "Ego局部坐标系" 改为 "以Ego位置为中心的世界坐标系"**

具体来说:
1. **体素网格中心** = Ego位置 (世界坐标) ✅
2. **体素网格坐标轴** = 世界坐标轴 (不旋转) ✅
3. **Actor检测逻辑**: 在世界坐标系中计算,不使用Ego旋转矩阵 ✅

#### 修复代码 1: 构建"纯平移"变换矩阵

**位置**: `generate()` 函数, Line 68-69

**修改前**:
```python
ego_transform = ego_vehicle.get_transform()
ego_matrix = np.array(ego_transform.get_matrix())  # ❌ 包含旋转
```

**修改后**:
```python
ego_transform = ego_vehicle.get_transform()
ego_location = ego_transform.location  # 只取位置

# ⭐ 构建纯平移变换矩阵 (不包含旋转)
# 体素网格坐标系: 以Ego位置为原点,对齐世界坐标轴
ego_matrix_translation_only = np.eye(4)
ego_matrix_translation_only[0, 3] = ego_location.x
ego_matrix_translation_only[1, 3] = ego_location.y
ego_matrix_translation_only[2, 3] = ego_location.z

# 用于体素网格的变换矩阵 (Grid坐标系 <-> 世界坐标系)
# Grid坐标系: 原点在Ego位置,但坐标轴对齐世界坐标轴
grid_to_world_matrix = ego_matrix_translation_only
```

**说明**:
- `grid_to_world_matrix` 是一个 **纯平移** 矩阵 (旋转部分是单位矩阵)
- Grid坐标系的原点 = Ego位置
- Grid坐标系的X/Y/Z轴 = 世界坐标系的X/Y/Z轴 (不旋转)

def _fill_actor_bb(self, occupancy, actor_ids_grid, actor, grid_to_world_matrix, is_ego=False):
    """
    Helper to rasterize an actor's bounding box into the occupancy grid

    Args:
        grid_to_world_matrix: 体素网格到世界坐标系的纯平移变换矩阵
                             (原点在Ego位置,坐标轴对齐世界坐标轴)
    """
    try:
        bb = actor.bounding_box
        actor_transform = actor.get_transform()
    except:
        return

    # ⭐ 核心修复：Grid -> World 变换矩阵的逆 (World -> Grid)
    # 因为 grid_to_world_matrix 是纯平移矩阵,逆矩阵也是纯平移
    try:
        world_to_grid_matrix = np.linalg.inv(grid_to_world_matrix)
    except np.linalg.LinAlgError:
        return

    # Get 8 corners in World
    verts_world = bb.get_world_vertices(actor_transform)
    if not verts_world:
        return

    verts_world_np = np.array([[v.x, v.y, v.z, 1.0] for v in verts_world]).T

    # ⭐ Transform to Grid (不是Ego局部坐标系,而是对齐世界的Grid坐标系)
    verts_grid_np = world_to_grid_matrix @ verts_world_np

    xs_grid = verts_grid_np[0, :]
    ys_grid = verts_grid_np[1, :]
    zs_grid = verts_grid_np[2, :]

    # Grid Indices Range (不变)
    min_ix = int(np.floor((np.min(xs_grid) - self.x_range[0]) / self.resolution))
    max_ix = int(np.ceil((np.max(xs_grid) - self.x_range[0]) / self.resolution))
    min_iy = int(np.floor((np.min(ys_grid) - self.y_range[0]) / self.resolution))
    max_iy = int(np.ceil((np.max(ys_grid) - self.y_range[0]) / self.resolution))
    min_iz = int(np.floor((np.min(zs_grid) - self.z_range[0]) / self.resolution))
    max_iz = int(np.ceil((np.max(zs_grid) - self.z_range[0]) / self.resolution))

    # ... (后续代码不变)
```

import numpy as np

def test_static_object_stability():
    """
    验证静态物体在车辆转弯时是否闪烁
    """
    # 采集100帧数据 (包含转弯)
    # 跟踪一个静态建筑物的Actor ID

    static_actor_id = 12345  # 某个建筑物ID
    voxel_positions = []

    for frame_idx in range(100):
        occupancy, actor_ids = generator.generate(world, ego_vehicle)

        # 找到该建筑物所在的体素位置
        mask = (actor_ids == static_actor_id)
        positions = np.argwhere(mask)

        if len(positions) > 0:
            # 计算质心
            centroid = positions.mean(axis=0)
            voxel_positions.append(centroid)

    voxel_positions = np.array(voxel_positions)

    # 检查位置稳定性
    # 对于静态物体,体素位置应该平滑变化 (只随Ego移动而相对位置变化)
    # 不应该有突变 (闪烁)

    position_diffs = np.diff(voxel_positions, axis=0)
    max_jump = np.max(np.linalg.norm(position_diffs, axis=1))

    print(f"静态物体最大跳跃距离: {max_jump:.2f} 体素")

    # 期望: 转弯时相对位置变化应该 < 5 个体素/帧
    # 如果 > 20 体素/帧 → 说明存在坐标系旋转问题
    assert max_jump < 10, f"检测到闪烁! 最大跳跃 {max_jump} 体素"
    print("✅ 静态物体位置稳定性测试通过")
```

    # 检查: 测试物体在两帧中的体素位置应该相同!
    # (因为物体和Ego位置都没变,只是Ego旋转了)

    # 找到测试物体的体素位置

        centroid1 = pos1.mean(axis=0)
        centroid2 = pos2.mean(axis=0)

        diff = np.linalg.norm(centroid1 - centroid2)
        print(f"Ego旋转前后体素位置差异: {diff:.2f} 体素")

        # 期望: 差异 < 1 体素 (舍入误差)
        assert diff < 1.0, f"坐标系未对齐! 差异 {diff}"
        print("✅ 坐标轴对齐验证通过")
    else:
        print("⚠️ 未检测到测试物体")

**体素网格坐标系随Ego车辆旋转**,导致静态物体在体素网格中的位置随车辆转弯而跳变。

### 修复核心

**将体素网格坐标系从 "Ego局部坐标系" 改为 "以Ego位置为中心的世界坐标系"**:
- 体素网格中心 = Ego位置 ✅
- 体素网格坐标轴 = 世界坐标轴 (不旋转) ✅

### 修改范围

**仅需修改 `ground_truth_voxel_generator.py` 一个文件**:
- 构建纯平移变换矩阵 `grid_to_world_matrix`
- 替换所有使用 `ego_matrix` 的地方

- ✅ 静态物体不再闪烁

- ✅ 数据集质量大幅提升
- ✅ 训练出的模型更加稳定可靠
