# 地面90度旋转变形问题 - 修复完成

## ✅ 修复摘要

**问题**: 车辆转弯90度后地面发生变形、错位或 Index 超限
**根因**: 使用世界坐标作为 Cache Key，导致旋转后填充到错误的网格位置
**解决**: 改用网格索引作为 Cache Key，每帧清空 Cache
**修复文件**: `dense_occupancy_collection/processing/ground_truth_voxel_generator.py`
**修改行数**: 4 处关键修改

---

## 🔧 修改详情

### 修改 1: 每帧清空 Cache（Line 166-176）

**目的**: 防止旧 Cache 在车辆旋转后导致错误映射

```python
# ⭐⭐⭐ CRITICAL FIX: 每帧清空 Cache ⭐⭐⭐
# 根因: 体素网格是 Ego-Aligned (随车辆旋转)
#       相同的网格索引 (ix, iy) 在不同旋转角度下对应不同的世界坐标
#       使用世界坐标作为 Cache Key 会导致:
#         yaw=0°:   grid(10,0) → world(ego_x+2, ego_y) → Road
#         yaw=90°:  grid(10,0) → world(ego_x, ego_y+2) → Sidewalk
#       但 Cache[(world_key)] 是跨帧复用的，导致旋转后填充错误！
#
# 解决: 每帧清空 Cache，使用网格索引作为 Key
self.ground_cache.clear()
print(f"[地面填充] 已清空旧 Cache (Ego-Aligned Grid 旋转后坐标映射改变)")
```

### 修改 2: 使用网格索引生成 Cache Key（Line 196-231）

**目的**: 直接使用 (ix, iy) 作为 Cache Key，避免世界坐标映射错误

**修改前**:

**修改后**:
```python

keys_y = np.arange(self.grid_size[1])  # [0, 1, 2, ..., 511]

points_world_h = points_grid_h @ grid_to_world_matrix.T

flat_wx = points_world_h[:, 0]
flat_wy = points_world_h[:, 1]
```

## 🎯 修复原理

### 问题根源

```
旧逻辑（错误）:
1. 网格索引 (ix, iy) → 网格坐标 (gx, gy)
2. 网格坐标 → 世界坐标 (wx, wy) [旋转!]
3. 世界坐标 → Cache Key: floor(wx/res), floor(wy/res)
4. Cache[(world_key)] = label
5. 填充: occupancy[ix, iy] = Cache[(world_key)]  ❌ 错误！

问题:
- yaw=0°:   grid(10,0) → world(100, 200) → key=(500, 1000) → Road
- yaw=90°:  grid(10,0) → world(100, 202) → key=(500, 1010) → Sidewalk
- 但两次都填充到 occupancy[10, 0]！导致地面类型错误！
```

### 修复逻辑

```
新逻辑（正确）:
1. 网格索引 (ix, iy) → Cache Key: (ix, iy)
2. 网格坐标 → 世界坐标 (wx, wy) [用于查询]
3. 查询 Map API: (wx, wy) → label
4. Cache[(ix, iy)] = label
5. 填充: occupancy[ix, iy] = Cache[(ix, iy)]  ✅ 正确！

优点:
- Cache Key 与填充目标完全一致
- 无坐标映射错误
- 旋转后仍然正确
```

## 💡 技术要点总结

### 为什么 Actor 没问题而地面有问题？

**Actor 填充**:
- ✅ 使用完整的 4x4 变换矩阵（包含旋转）
- ✅ 直接转换：世界坐标 → 网格坐标
- ✅ 无 Cache，实时计算
- ✅ 结果：与旋转角度无关

**地面填充（修复前）**:
- ❌ 两次转换：网格 → 世界 → Cache → 网格
- ❌ 使用世界坐标作为 Cache Key
- ❌ Cache Key 与填充目标不匹配
- ❌ 结果：旋转后映射错误

**地面填充（修复后）**:
- ✅ 使用网格索引作为 Cache Key
- ✅ Cache Key 与填充目标完全一致
- ✅ 每帧清空 Cache
- ✅ 结果：与旋转角度无关

### 关键设计原则

1. **Cache Key 应该与使用目标一致**
   - 地面填充的目标是 `occupancy[ix, iy, iz]`
   - 因此 Cache Key 应该是 `(ix, iy)` 而不是 `(wx, wy)`

2. **Ego-Aligned Grid 需要每帧更新**
   - 体素网格随车辆旋转
   - 相同的网格索引对应不同的世界坐标
   - Cache 必须每帧清空

3. **避免不必要的坐标转换**
   - 直接使用网格索引生成、查询、填充
   - 世界坐标仅用于 Map API 查询
