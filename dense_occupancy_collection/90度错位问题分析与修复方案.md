# 地面与建筑物 90 度错位问题分析与修复方案

## 🚨 问题现象

**修改后出现的新问题**:
- ✅ 地面不再闪烁 (世界对齐采样成功)
- ❌ **地面和建筑物 90 度错开** (严重坐标系不一致)
- ❌ 道路、人行道、建筑物的空间位置关系错乱

---

## 🔍 根本原因分析

### 核心矛盾：两种不兼容的坐标系同时存在

**当前代码存在致命矛盾**:

| 模块 | 坐标系类型 | 变换矩阵 | Grid X 轴定义 | Grid Y 轴定义 |
|------|-----------|---------|--------------|--------------|
| **地面填充** | Ego-Aligned | `world_to_ego` (含旋转) | Ego Forward (车头方向) | Ego Left (车体左方) |
| **建筑物填充** | World-Aligned | `grid_to_world` (纯平移) | World East (世界东向) | World North (世界北向) |
| **动态 Actor** | World-Aligned | `grid_to_world` (纯平移) | World East (世界东向) | World North (世界北向) |

**结果**:
- 地面使用 **车体坐标系** (随车辆旋转)
- 建筑物使用 **世界坐标系** (固定不动)
- **两者之间产生相对旋转 = 车辆 yaw 角**

---

## 📐 具体错位情况

### 情况 1: 车辆朝东 (yaw = 0°)

```
世界坐标系:  X→East, Y→North
Ego Forward: X→East, Y→North

地面 Grid X = Ego Forward = East  ✅
建筑 Grid X = World X = East      ✅

结果: 一致，无错位
```

### 情况 2: 车辆朝北 (yaw = 90°)

```
世界坐标系:  X→East, Y→North
Ego Forward: X→North, Y→West

地面 Grid X = Ego Forward = North  ❌
建筑 Grid X = World X = East       ❌

结果: 90° 错位！
```

### 情况 3: 车辆朝西 (yaw = 180°)

```
地面 Grid X = Ego Forward = West   ❌
建筑 Grid X = World X = East       ❌

结果: 180° 错位！
```

### 错误 2: 建筑物填充使用了 World-Aligned 坐标系

**文件**: `ground_truth_voxel_generator.py`

- 静态物体不会因车辆转弯而闪烁

## ✅ 修复方案

### 方案: 统一使用 World-Aligned 坐标系 (推荐)

**原则**: 让地面填充与建筑物填充保持一致

**修改位置**: `ground_truth_voxel_generator.py` 第 253-275 行

---

#### 当前错误代码:
```python
# 2. 将世界坐标转换到 Ego 坐标，再转换到 Grid 索引
# ⭐ 关键修复：需要先将 World -> Ego，再计算 Grid 索引
```

#### 正确代码:
```python
# 2. 将世界坐标转换到 Grid 索引
# ⭐ Grid 坐标系定义: World-Aligned (对齐世界坐标轴)
# - Grid 原点: Ego 位置 (ego_location)
# - Grid X 轴: World X (East, 东向)
# - Grid Y 轴: World Y (North, 北向)
# - Grid Z 轴: World Z (Up, 向上)
#
# 与 grid_to_world_matrix 定义保持一致 (纯平移矩阵)

# 计算世界坐标相对于 Ego 的偏移 (World-Aligned)
dx_world = wx - ego_location.x  # Grid X = World X offset
dy_world = wy - ego_location.y  # Grid Y = World Y offset
dz_world = wz - ego_location.z  # Grid Z = World Z offset

# Grid 坐标 (相对坐标，单位: 米)
gx = dx_world  # Grid X (World-Aligned East)
gy = dy_world  # Grid Y (World-Aligned North)
gz = dz_world  # Grid Z (World-Aligned Up)

# 转换到 Grid 索引 (数组索引)
# x_range = (-51.2, 51.2) -> [0, 512)
# y_range = (-51.2, 51.2) -> [0, 512)
# z_range = (-4.0, 4.0) -> [0, 40)
ix = int((gx - self.x_range[0]) / self.resolution)
iy = int((gy - self.y_range[0]) / self.resolution)
```

**关键修改**:
1. ✅ 移除了错误的注释 "Grid X = Ego Forward"
2. ✅ 明确说明 Grid 坐标系是 **World-Aligned**
3. ✅ 与 `grid_to_world_matrix` 的定义保持一致
4. ✅ Z 坐标基准改为 `ego_location.z` (车体中心高度)

## 🎓 坐标系知识补充

### CARLA/UE5 世界坐标系

```
   North (Y+)
      ↑
      |
      |
      └────→ East (X+)
     /
    /
   ↙ Up (Z+)
```

- X 轴: East (东向)
- Y 轴: North (北向)
- Z 轴: Up (向上)

### Grid 坐标系 (World-Aligned)

```
Grid 原点: Ego 位置
Grid 范围: x ∈ [-51.2, 51.2], y ∈ [-51.2, 51.2], z ∈ [-4.0, 4.0]

Grid 坐标轴:
- Grid X: World X (East) - Ego X 位置
- Grid Y: World Y (North) - Ego Y 位置
- Grid Z: World Z (Up) - Ego Z 位置

变换公式:
Grid (gx, gy, gz) = World (wx, wy, wz) - Ego (ex, ey, ez)
```

### Ego 坐标系 (Ego-Aligned) - 不推荐

```
Ego 原点: 车体中心
Ego 坐标轴 (跟随车辆旋转):
- Ego X: Forward (车头方向)
- Ego Y: Left (车体左方)
- Ego Z: Up (车体上方)

问题:
- 车辆转弯时，Ego X/Y 轴方向改变
- 静态物体会相对 Grid 旋转
- 导致地面条纹/闪烁问题
```

---

## ⚠️ 重要注意事项

### 不要混淆两种坐标系

**World-Aligned Grid** (推荐):
- Grid 坐标轴固定在世界坐标系上
- 只有原点随 Ego 移动 (平移)
- 车辆转弯时，Grid 不旋转

**Ego-Aligned Grid** (不推荐):
- Grid 坐标轴跟随车体旋转
- 车辆转弯时，Grid 整体旋转
- 静态物体会相对 Grid 旋转 → 闪烁

### 代码中的一致性检查

**统一原则**: 所有模块 (地面、建筑、动态 Actor) 必须使用同一个坐标系

**检查清单**:
- [ ] `grid_to_world_matrix` 只包含平移 (无旋转)
- [ ] 地面填充使用 `gx = wx - ego_x` (非 `world_to_ego @ p_world`)
- [ ] 建筑填充使用 `world_to_grid = inv(grid_to_world)`
- [ ] 动态 Actor 填充使用相同的 `grid_to_world_matrix`
