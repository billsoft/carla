## ✅ 修复方案: 向量化赋值

### 修复 1: 向量化地表填充 (Line 355-382)

**原代码** (慢):
```python
surface_fill_count = 0
for i in range(len(final_ix)):  # 262,144 次 Python 循环!
    ix, iy, iz, l = final_ix[i], final_iy[i], final_iz[i], final_l[i]

    current_val = occupancy[ix, iy, iz]
    if current_val == 0 or current_val == 12:
        occupancy[ix, iy, iz] = l
        actor_ids[ix, iy, iz] = -(1000 + l)
        surface_fill_count += 1

print(f"[地面填充] 地表层填充: {surface_fill_count} 个体素")
```

**问题**:
- Python `for` 循环在处理大规模数组时极慢
- 逐个索引访问无法利用 CPU 缓存
- **预计耗时: 10-15 秒**

---

**优化代码** (快):
```python
# ⭐⭐⭐ 性能优化: 向量化赋值,消除 Python 循环 ⭐⭐⭐
# 根因: Python for 循环在处理 26万次赋值时极慢 (10-15秒)
# 解决: 使用 NumPy 高级索引批量赋值 (0.1-0.5秒)
# 预计提速: 20-150 倍

import time
t_start = time.time()

# 1. 批量读取当前值 (利用 NumPy 的向量化操作)
current_vals = occupancy[final_ix, final_iy, final_iz]

# 2. 生成掩码: 只填充空位 (0) 或原有地面 (12)
fill_mask = (current_vals == 0) | (current_vals == 12)

# 3. 筛选需要填充的索引
valid_ix = final_ix[fill_mask]
valid_iy = final_iy[fill_mask]
valid_iz = final_iz[fill_mask]
valid_l = final_l[fill_mask]

# 4. 批量赋值 (瞬间完成,利用 C 语言底层优化)
occupancy[valid_ix, valid_iy, valid_iz] = valid_l
actor_ids[valid_ix, valid_iy, valid_iz] = -(1000 + valid_l.astype(np.int32))

surface_fill_count = len(valid_ix)
t_elapsed = time.time() - t_start

print(f"[地面填充] 地表层填充: {surface_fill_count} 个体素 (耗时: {t_elapsed:.3f}s)")
```

**技术原理**:
- **NumPy 高级索引 (Advanced Indexing)**: 使用数组作为索引,一次性访问多个元素
- **向量化操作**: 底层使用 C 语言实现,避免 Python 循环开销
- **批量赋值**: `occupancy[valid_ix, valid_iy, valid_iz] = valid_l` 一次完成所有赋值

**性能提升**:
- 预计耗时: **0.1-0.5 秒** (从 10-15 秒)
- **提速 20-150 倍**

## 🔍 技术细节

### NumPy 高级索引 vs Python 循环

**Python 循环 (慢)**:
```python
for i in range(N):
    array[x[i], y[i], z[i]] = value[i]
```
- 每次循环都有 Python 解释器开销
- 无法利用 SIMD 指令
- 缓存命中率低

**NumPy 高级索引 (快)**:
```python
array[x, y, z] = value
```
- 底层使用 C 语言实现
- 一次性分配内存,批量操作
- 可以利用 SIMD 指令加速
- 缓存命中率高

**性能差异**: 通常 **100+ 倍**

---

### 逻辑等价性证明

**原逻辑**:
```python
for i in range(N):
    if condition[i]:
        array[x[i], y[i], z[i]] = value[i]
```

**向量化逻辑**:
```python
mask = condition
array[x[mask], y[mask], z[mask]] = value[mask]
```

**证明**:
1. `mask` 是布尔数组,`mask[i] = condition[i]`
2. `x[mask]` 返回所有 `mask==True` 的 `x[i]`
3. `array[x[mask], y[mask], z[mask]]` 等价于所有满足条件的赋值
4. ✅ 完全等价

## ⚠️ 注意事项

### 1. 内存使用

**向量化操作会创建临时数组**:
```python
current_vals = occupancy[final_ix, final_iy, final_iz]  # 临时数组: 262,144 个 uint8
fill_mask = (current_vals == 0) | (current_vals == 12)  # 临时数组: 262,144 个 bool
valid_ix = final_ix[fill_mask]  # 临时数组: 约 200,000 个 int32
# ...
```

**内存占用** (临时):
- `current_vals`: 262KB
- `fill_mask`: 262KB
- `valid_ix, valid_iy, valid_iz, valid_l`: 约 3MB
- **总计**: 约 **4MB** (可忽略)

**结论**: ✅ 内存开销可接受

---

### 2. 数据类型

**重要**: `actor_ids` 使用 `int32` 类型:
```python
actor_ids[valid_ix, valid_iy, valid_iz] = -(1000 + valid_l.astype(np.int32))
```

**原因**:
- `valid_l` 是 `uint8` (0-255)
- `-1000` 是负数,需要有符号类型
- 必须转换为 `int32` 避免溢出

---
