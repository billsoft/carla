# 地面条纹闪烁问题 - 终极修复方案

## ✅ 修复总结

**问题**: 地面出现横向条纹闪烁,像栅栏一样
**根因**: Cache 分辨率过大 (1.0m) 导致多个体素共享同一 Cache Cell,产生阶梯状 Z 高度
**解决**: 降低 Cache 分辨率至 0.2m (与体素分辨率一致)
**修复文件**: `dense_occupancy_collection/processing/ground_truth_voxel_generator.py`

## 💡 技术原理

### 为什么 cache_res 必须等于 self.resolution?

**原理**:
```
cache_res = 1.0m:
  - Cache Cell 覆盖 5×5 = 25 个体素 (每个 0.2m)
  - 所有体素共享同一个 Z 高度
  - 产生"台阶"效应 → 条纹闪烁

cache_res = 0.2m:
  - Cache Cell 覆盖 1×1 = 1 个体素
  - 每个体素有独立的 Z 高度
  - 地面平滑 ✅
```

### 为什么必须每帧清空 Cache?

**原理**:
```
体素网格是 Ego-Aligned (随车辆旋转):
  - yaw=0°:   grid(10,0) → world(ego_x+2.0, ego_y)
  - yaw=90°:  grid(10,0) → world(ego_x, ego_y+2.0)

如果 Cache 不清空:
  - yaw=0°:  Cache[(10,0)] = Road
  - yaw=90°: Cache[(10,0)] 仍然是 Road (错误!)
  - 实际上 grid(10,0) 已经对应不同的世界坐标

每帧清空 Cache:
  - yaw=0°:  Cache[(10,0)] = Road
  - yaw=90°: Cache 清空, 重新查询 grid(10,0) → Sidewalk ✅
```

### 为什么使用网格索引作为 Cache Key?

**原理**:
```
使用世界坐标 Key (错误):
  - grid(10,0) → world(100, 200) → key=(500, 1000)
  - 旋转后: grid(10,0) → world(100, 202) → key=(500, 1010)
  - 两个不同的 Key,但填充到同一个 grid(10,0)
  - Cache 无法复用 ❌

使用网格索引 Key (正确):
  - grid(10,0) → key=(10, 0)
  - 旋转后: grid(10,0) → key=(10, 0) (相同!)
  - Cache Key 与填充目标完全一致 ✅
```
