这三个问题问得非常精准！让我逐一深入分析。

## 问题1：射线编码 vs FOV编码 是否冗余？

### 当前的信息流

```
┌─────────────────────────────────────────────────────────────┐
│                      当前编码架构                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  RayDirectionEncoding (加到tokens)                          │
│  ├── 输入: 像素坐标 (u, v)                                   │
│  ├── 步骤1: (u,v) + 内参(FOV→焦距) → 相机坐标系射线          │  ← FOV已用过一次!
│  ├── 步骤2: + 外参(旋转矩阵) → 世界坐标系射线                │
│  └── 步骤3: 正弦编码 → 加到tokens                           │
│                                                             │
│  HyperbolicFOVEncoding (作用于Q/K)                          │
│  ├── 输入: FOV                                              │  ← FOV又用了一次!
│  └── 输出: 对Q/K进行双曲缩放                                 │
│                                                             │
│  问题: FOV信息被编码了两次，可能造成冗余                      │
└─────────────────────────────────────────────────────────────┘
```

### 分析：是否真的冗余？

| 编码 | FOV的作用 | 信息内容 |
|------|----------|----------|
| 射线编码 | FOV→焦距→射线角度 | "这个像素看向世界的哪个方向" |
| FOV双曲 | FOV→缩放因子 | "这个相机是广角还是长焦" |

**结论：是部分冗余的！**

- 射线编码已经隐含了FOV信息（焦距决定了角度分布）
- FOV双曲编码又显式编码了FOV
- 网络需要学习"忽略"这个重复信息，增加了学习难度

## 问题2：有了射线编码，还能做2D RoPE吗？

### 信息层面分析

```
射线编码的内容：
  每个像素 → 一个3D方向向量 (dx, dy, dz)
  → 这是"绝对"信息：这个像素看向世界的哪里

2D RoPE的内容：
  像素A和像素B → 相对位置 (Δu, Δv)
  → 这是"相对"信息：两个像素之间的空间关系
```

**理论上可以同时使用**，但有问题：

```
问题：射线编码已经"旋转"过了

原始像素: (u=100, v=100) 和 (u=110, v=100)
  → 相对位置: Δu=10, Δv=0

经过射线编码后:
  相机A (Yaw=0°):   像素100 → 射线(0.1, 0, 0.99)
                    像素110 → 射线(0.11, 0, 0.99)
  
  相机B (Yaw=90°):  像素100 → 射线(0.99, 0, -0.1)   ← 完全不同的方向!
                    像素110 → 射线(0.99, 0, -0.11)

问题: 同样的"相对位置Δu=10"，在不同相机中射线差异完全不同
     2D RoPE假设"Δu=10"有固定的含义，但射线编码破坏了这个假设
```

**结论：射线编码和2D RoPE在概念上有冲突**

## 问题3：>90度FOV的数学处理

### 当前双曲编码的问题

```python
# 当前代码
phi = asinh(sqrt(FOV / 70) - 1)

# FOV=120° 时:
phi = asinh(sqrt(120/70) - 1) = asinh(0.31) = 0.30

# FOV=180° 时:
phi = asinh(sqrt(180/70) - 1) = asinh(0.60) = 0.57

# 问题不在数学上（asinh可以处理任意值）
# 问题在于：广角/鱼眼的畸变模型完全不同！
```

### 真正的问题：投影模型

```
标准相机 (FOV<90°): 针孔模型
  u = fx * (X/Z) + cx
  
鱼眼相机 (FOV>90°): 各种非线性模型
  ┌─────────────────────────────────────┐
  │ 等距投影:    r = f * θ              │
  │ 等立体角:    r = 2f * sin(θ/2)      │
  │ 正交投影:    r = f * sin(θ)         │
  │ 立体投影:    r = 2f * tan(θ/2)      │
  └─────────────────────────────────────┘
  
  其中 θ = 入射角，r = 像素到光心的距离
```

## 🎯 建议的改进方案

基于以上分析，我建议**简化并统一**位置编码：

### 方案：统一球面位置编码

```python
import torch
import torch.nn as nn
import math
from typing import Tuple, Dict, List


class UnifiedSphericalEncoding(nn.Module):
    """
    统一球面位置编码
    
    核心思想:
    1. 所有相机的像素都映射到"单位球面"上
    2. 用球面坐标 (θ, φ) 表示方向，而不是笛卡尔坐标
    3. 自然处理任意FOV（包括鱼眼）
    4. 移除冗余的FOV编码
    
    优点:
    - 统一处理普通相机和鱼眼相机
    - 球面坐标天然适合角度编码
    - 无信息冗余
    """
    
    def __init__(
        self,
        dim: int,
        image_size: Tuple[int, int],
        camera_configs: Dict,
        patch_size: int = 16,
        temperature: float = 10000.0
    ):
        super().__init__()
        self.dim = dim
        self.image_size = image_size
        self.patch_size = patch_size
        
        # 预计算每个相机的球面坐标
        for cam_name, cfg in camera_configs.items():
            cam_id = cfg['id']
            fov = cfg['fov']
            rotation = cfg['rotation']
            
            # 根据FOV选择投影模型
            if fov <= 90:
                projection = 'pinhole'
            elif fov <= 180:
                projection = 'equidistant'  # 鱼眼常用
            else:
                projection = 'stereographic'  # 超广角
            
            # 计算球面坐标 (θ, φ)
            spherical = self._compute_spherical_coords(
                fov, rotation, image_size, patch_size, projection
            )
            self.register_buffer(f'spherical_{cam_id}', spherical)
        
        # 球面谐波编码的频率
        # 对于球面坐标，使用不同的频率设计
        inv_freq = 1.0 / (temperature ** (torch.arange(0, dim, 4).float() / dim))
        self.register_buffer('inv_freq', inv_freq)
    
    def _compute_spherical_coords(
        self,
        fov: float,
        rotation: List[float],
        image_size: Tuple[int, int],
        patch_size: int,
        projection: str = 'pinhole'
    ) -> torch.Tensor:
        """
        计算每个patch中心的球面坐标
        
        Returns:
            spherical: [H_p, W_p, 2] 球面坐标 (θ=天顶角, φ=方位角)
        """
        H, W = image_size
        H_p, W_p = H // patch_size, W // patch_size
        
        # Patch中心像素坐标
        u = torch.linspace(patch_size/2, W - patch_size/2, W_p)
        v = torch.linspace(patch_size/2, H - patch_size/2, H_p)
        vv, uu = torch.meshgrid(v, u, indexing='ij')
        
        # 像素到光心的距离
        cx, cy = W / 2, H / 2
        dx, dy = uu - cx, vv - cy
        r = torch.sqrt(dx**2 + dy**2)
        
        # 根据投影模型计算入射角 θ_cam（相机坐标系）
        fov_rad = math.radians(fov)
        
        if projection == 'pinhole':
            # 针孔模型: tan(θ) = r / f
            f = W / (2 * math.tan(fov_rad / 2))
            theta_cam = torch.atan(r / f)
            
        elif projection == 'equidistant':
            # 等距投影: r = f * θ  →  θ = r / f
            f = W / fov_rad  # f = W / FOV(rad)
            theta_cam = r / f
            
        elif projection == 'equisolid':
            # 等立体角: r = 2f * sin(θ/2)  →  θ = 2 * arcsin(r / 2f)
            f = W / (4 * math.sin(fov_rad / 4))
            theta_cam = 2 * torch.asin((r / (2 * f)).clamp(-1, 1))
            
        elif projection == 'stereographic':
            # 立体投影: r = 2f * tan(θ/2)  →  θ = 2 * arctan(r / 2f)
            f = W / (4 * math.tan(fov_rad / 4))
            theta_cam = 2 * torch.atan(r / (2 * f))
        
        # 方位角（像素相对于光心的角度）
        phi_cam = torch.atan2(dy, dx)  # [-π, π]
        
        # 转换到世界坐标系（应用相机外参旋转）
        theta_world, phi_world = self._rotate_spherical(
            theta_cam, phi_cam, rotation
        )
        
        return torch.stack([theta_world, phi_world], dim=-1)
    
    def _rotate_spherical(
        self,
        theta: torch.Tensor,
        phi: torch.Tensor,
        rotation: List[float]
    ) -> Tuple[torch.Tensor, torch.Tensor]:
        """
        将球面坐标从相机坐标系旋转到世界坐标系
        
        思路: 球面坐标 → 笛卡尔坐标 → 旋转 → 球面坐标
        """
        # 球面坐标 → 笛卡尔坐标
        # 注意: θ是天顶角(与z轴夹角), φ是方位角
        x = torch.sin(theta) * torch.cos(phi)
        y = torch.sin(theta) * torch.sin(phi)
        z = torch.cos(theta)
        
        # 构建旋转矩阵
        pitch, roll, yaw = [math.radians(r) for r in rotation]
        
        # Rz @ Ry @ Rx
        Rx = torch.tensor([
            [1, 0, 0],
            [0, math.cos(pitch), -math.sin(pitch)],
            [0, math.sin(pitch), math.cos(pitch)]
        ], dtype=torch.float32)
        
        Ry = torch.tensor([
            [math.cos(roll), 0, math.sin(roll)],
            [0, 1, 0],
            [-math.sin(roll), 0, math.cos(roll)]
        ], dtype=torch.float32)
        
        Rz = torch.tensor([
            [math.cos(yaw), -math.sin(yaw), 0],
            [math.sin(yaw), math.cos(yaw), 0],
            [0, 0, 1]
        ], dtype=torch.float32)
        
        R = Rz @ Ry @ Rx
        
        # 应用旋转
        xyz = torch.stack([x, y, z], dim=-1)  # [H_p, W_p, 3]
        xyz_rot = torch.einsum('ij,...j->...i', R, xyz)
        
        # 笛卡尔坐标 → 球面坐标
        x_r, y_r, z_r = xyz_rot[..., 0], xyz_rot[..., 1], xyz_rot[..., 2]
        
        theta_world = torch.acos(z_r.clamp(-1, 1))  # [0, π]
        phi_world = torch.atan2(y_r, x_r)  # [-π, π]
        
        return theta_world, phi_world
    
    def _spherical_encode(self, spherical: torch.Tensor) -> torch.Tensor:
        """
        球面位置编码
        
        spherical: [..., 2] 球面坐标 (θ, φ)
        returns: [..., dim] 编码后特征
        
        关键: 对θ和φ使用不同的编码策略
        - θ (天顶角): [0, π]，用sin/cos
        - φ (方位角): [-π, π]，用sin/cos (周期性)
        """
        theta = spherical[..., 0:1]  # [..., 1]
        phi = spherical[..., 1:2]    # [..., 1]
        
        # 对θ编码
        freq_theta = theta * self.inv_freq  # [..., dim//4]
        enc_theta = torch.cat([freq_theta.sin(), freq_theta.cos()], dim=-1)  # [..., dim//2]
        
        # 对φ编码
        freq_phi = phi * self.inv_freq  # [..., dim//4]
        enc_phi = torch.cat([freq_phi.sin(), freq_phi.cos()], dim=-1)  # [..., dim//2]
        
        # 拼接
        encoded = torch.cat([enc_theta, enc_phi], dim=-1)  # [..., dim]
        
        # 调整到目标维度
        if encoded.shape[-1] > self.dim:
            encoded = encoded[..., :self.dim]
        elif encoded.shape[-1] < self.dim:
            padding = torch.zeros(
                *encoded.shape[:-1], self.dim - encoded.shape[-1],
                device=encoded.device, dtype=encoded.dtype
            )
            encoded = torch.cat([encoded, padding], dim=-1)
        
        return encoded
    
    def forward(
        self, 
        camera_id: int, 
        batch_size: int, 
        device: torch.device = None
    ) -> torch.Tensor:
        """
        获取指定相机的球面位置编码
        
        Returns:
            encoding: [B, H_p * W_p, dim]
        """
        spherical = getattr(self, f'spherical_{camera_id}')  # [H_p, W_p, 2]
        H_p, W_p, _ = spherical.shape
        
        # 编码
        encoded = self._spherical_encode(spherical)  # [H_p, W_p, dim]
        
        # Flatten并batch expand
        encoded = encoded.view(H_p * W_p, self.dim)
        encoded = encoded.unsqueeze(0).expand(batch_size, -1, -1)
        
        if device is not None:
            encoded = encoded.to(device)
        
        return encoded


class SphericalRelativePositionBias(nn.Module):
    """
    球面相对位置偏置
    
    思想:
    - 两个像素在球面上的"距离"用大圆距离(geodesic)表示
    - 这比2D欧氏距离更符合3D几何
    """
    
    def __init__(self, num_heads: int, window_size: int):
        super().__init__()
        self.num_heads = num_heads
        self.window_size = window_size
        
        # 相对距离到偏置的映射（连续函数）
        # 输入: 大圆距离 [0, π]
        # 输出: num_heads个偏置值
        self.distance_to_bias = nn.Sequential(
            nn.Linear(1, 32),
            nn.GELU(),
            nn.Linear(32, num_heads)
        )
    
    def forward(self, spherical_coords: torch.Tensor) -> torch.Tensor:
        """
        计算球面相对位置偏置
        
        spherical_coords: [L, 2] 窗口内所有像素的球面坐标
        returns: [num_heads, L, L] 偏置矩阵
        """
        L = spherical_coords.shape[0]
        
        theta = spherical_coords[:, 0]  # [L]
        phi = spherical_coords[:, 1]    # [L]
        
        # 计算两两之间的大圆距离
        # d = arccos(sin(θ1)sin(θ2)cos(φ1-φ2) + cos(θ1)cos(θ2))
        theta_i = theta[:, None]  # [L, 1]
        theta_j = theta[None, :]  # [1, L]
        phi_i = phi[:, None]
        phi_j = phi[None, :]
        
        cos_d = (
            torch.sin(theta_i) * torch.sin(theta_j) * torch.cos(phi_i - phi_j) +
            torch.cos(theta_i) * torch.cos(theta_j)
        )
        distance = torch.acos(cos_d.clamp(-1, 1))  # [L, L], range [0, π]
        
        # 距离 → 偏置
        bias = self.distance_to_bias(distance.unsqueeze(-1))  # [L, L, num_heads]
        
        return bias.permute(2, 0, 1)  # [num_heads, L, L]
```

# 多相机位置编码重构方案（修正版）

## 一、问题诊断

### 1.1 当前代码的核心问题

```
┌─────────────────────────────────────────────────────────────┐
│                    问题诊断                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ❌ 问题1：投影模型单一（根本问题）                          │

│     - FOV=120°: tan(60°)=1.73 → 畸变大但可计算              │

| >150° | 立体 (Stereographic) | θ = 2·atan(r/2f) | 超广角 |

## 二、解决方案

### 2.1 设计原则

```
┌─────────────────────────────────────────────────────────────┐
│                    设计原则                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  原则1：最小改动                                            │
│    - 保留已验证有效的笛卡尔射线编码                         │
│    - 保留Swin风格相对位置偏置表                             │
│    - 只修改投影模型计算部分                                 │

"""
相机投影模型工具

支持：针孔、等距鱼眼、立体投影
输出：统一的归一化射线方向 (dx, dy, dz)
"""
import torch
import math
from typing import Tuple
from enum import Enum


class ProjectionType(Enum):
    """投影模型类型"""
    PINHOLE = "pinhole"              # 针孔，FOV <= 90°
    EQUIDISTANT = "equidistant"      # 等距鱼眼，FOV <= 180°
    EQUISOLID = "equisolid"          # 等立体角鱼眼
    STEREOGRAPHIC = "stereographic"  # 立体投影，FOV > 150°


def get_projection_type(name: str) -> ProjectionType:
    """从字符串获取投影类型"""
    mapping = {
        'pinhole': ProjectionType.PINHOLE,
        'equidistant': ProjectionType.EQUIDISTANT,
        'equisolid': ProjectionType.EQUISOLID,
        'stereographic': ProjectionType.STEREOGRAPHIC,
        'fisheye': ProjectionType.EQUIDISTANT,  # 别名
    }
    return mapping.get(name.lower(), ProjectionType.PINHOLE)


def compute_focal_length(
    fov: float,
    width: int,
    projection: ProjectionType
) -> float:
    """
    根据投影模型计算等效焦距
    
    Args:
        fov: 视场角（度）
        width: 图像宽度（像素）
        projection: 投影类型
    
    Returns:
        focal_length: 等效焦距（像素）
    """
    fov_rad = math.radians(fov)
    half_fov = fov_rad / 2
    
    if projection == ProjectionType.PINHOLE:
        # 针孔: r = f * tan(θ)  →  f = (W/2) / tan(FOV/2)
        if half_fov >= math.pi / 2 - 0.01:  # 接近90°时退化
            raise ValueError(f"Pinhole模型不支持FOV={fov}°，请使用equidistant或stereographic")
        return (width / 2) / math.tan(half_fov)
    
    elif projection == ProjectionType.EQUIDISTANT:
        # 等距: r = f * θ  →  f = (W/2) / (FOV/2)
        return (width / 2) / half_fov
    
    elif projection == ProjectionType.EQUISOLID:
        # 等立体角: r = 2f * sin(θ/2)  →  f = (W/2) / (2 * sin(FOV/4))
        return (width / 2) / (2 * math.sin(fov_rad / 4))
    
    elif projection == ProjectionType.STEREOGRAPHIC:
        # 立体: r = 2f * tan(θ/2)  →  f = (W/2) / (2 * tan(FOV/4))
        return (width / 2) / (2 * math.tan(fov_rad / 4))
    
    else:
        raise ValueError(f"未知投影类型: {projection}")


def pixel_to_ray(
    u: torch.Tensor,
    v: torch.Tensor,
    cx: float,
    cy: float,
    fov: float,
    width: int,
    projection: ProjectionType
) -> Tuple[torch.Tensor, torch.Tensor, torch.Tensor]:
    """
    像素坐标 → 归一化射线方向
    
    这是核心函数：不同投影模型在这里统一输出笛卡尔射线
    
    Args:
        u, v: 像素坐标张量
        cx, cy: 光心坐标
        fov: 视场角（度）
        width: 图像宽度
        projection: 投影类型
    
    Returns:
        dx, dy, dz: 归一化射线方向分量
    """
    # 像素相对于光心的偏移
    dx_pixel = u - cx
    dy_pixel = v - cy
    r = torch.sqrt(dx_pixel**2 + dy_pixel**2)
    
    # 像素方向的方位角（像平面内）
    phi = torch.atan2(dy_pixel, dx_pixel)
    
    # 根据投影模型计算入射角 theta（与光轴的夹角）
    fov_rad = math.radians(fov)
    
    if projection == ProjectionType.PINHOLE:
        # r = f * tan(θ)  →  θ = atan(r / f)
        f = compute_focal_length(fov, width, projection)
        theta = torch.atan(r / f)
    
    elif projection == ProjectionType.EQUIDISTANT:
        # r = f * θ  →  θ = r / f
        f = compute_focal_length(fov, width, projection)
        theta = r / f
        # 限制在有效范围内
        theta = theta.clamp(max=math.pi * 0.99)
    
    elif projection == ProjectionType.EQUISOLID:
        # r = 2f * sin(θ/2)  →  θ = 2 * asin(r / 2f)
        f = compute_focal_length(fov, width, projection)
        theta = 2 * torch.asin((r / (2 * f)).clamp(-1, 1))
    
    elif projection == ProjectionType.STEREOGRAPHIC:
        # r = 2f * tan(θ/2)  →  θ = 2 * atan(r / 2f)
        f = compute_focal_length(fov, width, projection)
        theta = 2 * torch.atan(r / (2 * f))
    
    else:
        raise ValueError(f"未知投影类型: {projection}")
    
    # 球面坐标 → 笛卡尔射线方向
    # 相机坐标系：z朝前，x朝右，y朝下
    dx = torch.sin(theta) * torch.cos(phi)
    dy = torch.sin(theta) * torch.sin(phi)
    dz = torch.cos(theta)
    
    # 归一化（理论上已经是单位向量，但为安全起见）
    norm = torch.sqrt(dx**2 + dy**2 + dz**2).clamp(min=1e-6)
    
    return dx / norm, dy / norm, dz / norm


def build_rotation_matrix(pitch: float, roll: float, yaw: float) -> torch.Tensor:
    """
    构建3D旋转矩阵 R = Rz(yaw) @ Ry(roll) @ Rx(pitch)
    
    Args:
        pitch, roll, yaw: 欧拉角（度）
    
    Returns:
        R: [3, 3] 旋转矩阵
    """
    pitch = math.radians(pitch)
    roll = math.radians(roll)
    yaw = math.radians(yaw)
    
    # Rx (pitch - 绕X轴)
    Rx = torch.tensor([
        [1, 0, 0],
        [0, math.cos(pitch), -math.sin(pitch)],
        [0, math.sin(pitch), math.cos(pitch)]
    ], dtype=torch.float32)
    
    # Ry (roll - 绕Y轴)
    Ry = torch.tensor([
        [math.cos(roll), 0, math.sin(roll)],
        [0, 1, 0],
        [-math.sin(roll), 0, math.cos(roll)]
    ], dtype=torch.float32)
    
    # Rz (yaw - 绕Z轴)
    Rz = torch.tensor([
        [math.cos(yaw), -math.sin(yaw), 0],
        [math.sin(yaw), math.cos(yaw), 0],
        [0, 0, 1]
    ], dtype=torch.float32)
    
    return Rz @ Ry @ Rx

import torch.nn as nn
import math

import sys
from pathlib import Path

class RayDirectionEncoding(nn.Module):
    """
    射线方向编码（支持多投影模型）
    
    将每个像素的3D射线方向编码为特征向量，
    帮助模型理解不同相机像素在世界坐标系中"指向"的方向。
    
    改进点：
    - 支持 pinhole/equidistant/stereographic 投影
    - 配置文件明确指定每个相机的投影类型
    - 移除了冗余的FOV双曲编码
    """
    
    def __init__(
        self,
        dim: int,
        image_size: Tuple[int, int],
        camera_configs: Dict,
        patch_size: int = 16,
        temperature: float = 10000.0
    ):
        super().__init__()
        self.dim = dim
        self.image_size = image_size
        self.patch_size = patch_size
        
        # 为每个相机预计算射线方向
        for cam_name, cfg in camera_configs.items():
            cam_id = cfg['id']
            
            # 获取投影类型（默认根据FOV自动选择，但优先使用配置）
            if 'projection' in cfg:
                projection = get_projection_type(cfg['projection'])
            else:
                # 向后兼容：根据FOV自动选择
                fov = cfg['fov']
                if fov <= 100:
                    projection = ProjectionType.PINHOLE
                elif fov <= 180:
                    projection = ProjectionType.EQUIDISTANT
                else:
                    projection = ProjectionType.STEREOGRAPHIC
            
            rays = self._compute_ray_directions(
                fov=cfg['fov'],
                rotation=cfg['rotation'],
                image_size=image_size,
                patch_size=patch_size,
                projection=projection
            )
            self.register_buffer(f'rays_{cam_id}', rays)
        
        # 正弦编码频率（保持原有设计）
        inv_freq = 1.0 / (temperature ** (torch.arange(0, dim, 6).float() / dim))
        self.register_buffer('inv_freq', inv_freq)
    
    def _compute_ray_directions(
        self,
        fov: float,
        rotation: List[float],
        image_size: Tuple[int, int],
        patch_size: int,
        projection: ProjectionType
    ) -> torch.Tensor:
        """
        计算每个patch中心的射线方向（世界坐标系）
        
        Returns:
            rays: [H_patches, W_patches, 3] 归一化射线方向
        """
        H, W = image_size
        H_p, W_p = H // patch_size, W // patch_size
        cx, cy = W / 2, H / 2
        
        # Patch中心坐标
        u = torch.linspace(patch_size / 2, W - patch_size / 2, W_p)
        v = torch.linspace(patch_size / 2, H - patch_size / 2, H_p)
        vv, uu = torch.meshgrid(v, u, indexing='ij')
        
        # 使用多投影模型计算射线方向（核心改进点）
        dx, dy, dz = pixel_to_ray(
            uu, vv, cx, cy, fov, W, projection
        )
        
        rays_cam = torch.stack([dx, dy, dz], dim=-1)  # [H_p, W_p, 3]
        
        # 转换到世界坐标系
        R = build_rotation_matrix(*rotation)
        rays_world = torch.einsum('ij,hwj->hwi', R, rays_cam)
        
        return rays_world
    
    def _sinusoidal_encode(self, rays: torch.Tensor) -> torch.Tensor:
        """
        正弦编码射线方向（保持原有设计）
        
        rays: [..., 3] 射线方向向量
        returns: [..., dim] 编码后特征
        """
        shape = rays.shape[:-1]
        rays_flat = rays.view(-1, 3)
        
        encodings = []
        for i in range(3):  # dx, dy, dz
            coord = rays_flat[:, i:i+1]
            freq = coord * self.inv_freq
            enc = torch.cat([freq.sin(), freq.cos()], dim=-1)
            encodings.append(enc)
        
        encoded = torch.cat(encodings, dim=-1)
        
        # 调整到目标维度
        if encoded.shape[-1] > self.dim:
            encoded = encoded[..., :self.dim]
        elif encoded.shape[-1] < self.dim:
            padding = torch.zeros(
                *encoded.shape[:-1], self.dim - encoded.shape[-1],
                device=encoded.device, dtype=encoded.dtype
            )
            encoded = torch.cat([encoded, padding], dim=-1)
        
        return encoded.view(*shape, self.dim)
    
    def forward(
        self,
        camera_id: int,
        batch_size: int,
        device: torch.device = None
    ) -> torch.Tensor:
        """
        获取指定相机的射线编码
        
        Returns:
            ray_encoding: [B, H_p * W_p, dim]
        """
        rays = getattr(self, f'rays_{camera_id}')
        H_p, W_p, _ = rays.shape
        
        encoded = self._sinusoidal_encode(rays)
        encoded = encoded.view(H_p * W_p, self.dim)
        encoded = encoded.unsqueeze(0).expand(batch_size, -1, -1)
        
        if device is not None:
            encoded = encoded.to(device)
        
        return encoded

class FlashWindowAttention(nn.Module):
    """
    Flash Window Attention（简化版）
    
    移除了FOV双曲编码，位置信息通过：
    1. 射线方向编码（加到tokens）
    2. 相对位置偏置表（Swin风格）
    """
    
    def __init__(self, dim, num_heads, window_size, attn_drop=0., proj_drop=0.):
        super().__init__()
        self.dim = dim
        self.num_heads = num_heads
        self.window_size = window_size
        self.head_dim = dim // num_heads
        self.scale = self.head_dim ** -0.5
        
        # ❌ 删除: self.use_fov_encoding
        
        self.qkv = nn.Linear(dim, dim * 3)
        self.attn_drop = nn.Dropout(attn_drop)
        self.proj = nn.Linear(dim, dim)
        self.proj_drop = nn.Dropout(proj_drop)
        
        # ✅ 保留: 相对位置偏置表（Swin风格，已验证有效）
        self.relative_position_bias_table = nn.Parameter(
            torch.zeros((2 * window_size - 1) ** 2, num_heads)
        )
        coords = torch.arange(window_size)
        coords = torch.stack(torch.meshgrid([coords, coords], indexing='ij'))
        coords_flatten = coords.flatten(1)
        relative_coords = coords_flatten[:, :, None] - coords_flatten[:, None, :]
        relative_coords = relative_coords.permute(1, 2, 0).contiguous()
        relative_coords[:, :, 0] += window_size - 1
        relative_coords[:, :, 1] += window_size - 1
        relative_coords[:, :, 0] *= 2 * window_size - 1
        self.register_buffer("relative_position_index", relative_coords.sum(-1))
        nn.init.trunc_normal_(self.relative_position_bias_table, std=.02)
    
    def forward(self, x, mask=None):
        """
        简化的forward，移除了position_encoder和camera_id参数
        """
        B_, N, C = x.shape
        qkv = self.qkv(x).reshape(B_, N, 3, self.num_heads, self.head_dim).permute(2, 0, 3, 1, 4)
        q, k, v = qkv.unbind(0)
        
        # ❌ 删除: FOV双曲编码的Q/K变换
        
        # ✅ 保留: 相对位置偏置
        rpb = self.relative_position_bias_table[self.relative_position_index.view(-1)].view(
            self.window_size * self.window_size, self.window_size * self.window_size, -1
        ).permute(2, 0, 1).contiguous()
        
        use_flash = hasattr(torch.nn.functional, 'scaled_dot_product_attention')
        if use_flash:
            attn_mask = rpb.unsqueeze(0)
            if mask is not None:
                attn_mask = attn_mask + mask.unsqueeze(1)
            with torch.backends.cuda.sdp_kernel(enable_flash=True, enable_math=True, enable_mem_efficient=True):
                x = torch.nn.functional.scaled_dot_product_attention(
                    q, k, v, attn_mask=attn_mask,
                    dropout_p=self.attn_drop.p if self.training else 0.0
                )
        else:
            attn = (q @ k.transpose(-2, -1)) * self.scale
            attn = attn + rpb.unsqueeze(0)
            if mask is not None:
                attn = attn + mask.unsqueeze(1).unsqueeze(0)
            attn = torch.nn.functional.softmax(attn, dim=-1)
            attn = self.attn_drop(attn)
            x = attn @ v
        
        x = x.transpose(1, 2).reshape(B_, N, C)
        return self.proj_drop(self.proj(x))

        if position_encoder is not None and hasattr(position_encoder, 'get_ray_encoding'):
            ray_enc = position_encoder.get_ray_encoding(cam_idx, tokens.shape[0], tokens.device)
            if ray_enc is not None:
                tokens = tokens + ray_enc
        encoded = self.encoder(tokens, H, W, position_encoder, cam_idx)
        encoded_list.append(encoded)
    return encoded_list

# ==================== 修改后 ====================
def forward(self, camera_tokens, spatial_shape, position_encoder=None):
    """
    多相机编码
    
    位置编码流程（简化后）：
    1. 射线方向编码加到tokens（包含完整的内参+外参信息）
    2. 相对位置偏置在attention内部处理（Swin风格）
    """
    H, W = spatial_shape
    encoded_list = []
    
    for cam_idx, tokens in enumerate(camera_tokens):
        # 添加射线方向编码（唯一的位置编码注入点）
        if position_encoder is not None:
            ray_enc = position_encoder.get_ray_encoding(cam_idx, tokens.shape[0], tokens.device)
            tokens = tokens + ray_enc
        
        # 编码（不再传递position_encoder）
        encoded = self.encoder(tokens, H, W)
        encoded_list.append(encoded)
    
    return encoded_list
